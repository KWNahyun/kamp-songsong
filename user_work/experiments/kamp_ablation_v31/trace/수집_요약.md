# 기존 D-FINE/MAL 내부 추적: 수집 완료 기록

2026-09-30. 기본형·MAL 각 3개 checkpoint, validation 각 64장. 총 384번 계측 forward 모두 원 forward와 최종 박스·logit 차이 0. 모델은 eval 모드로 유지했다.

아래 값은 score 제한 없는 GT별 IoU≥0.5 후보 존재 수의 seed 평균이다. 같은 후보가 여러 GT에 대응할 수 있는 oracle 진단으로, 일대일 매칭 검출 Recall이나 AP가 아니다. 각 행의 분모는 동일한 GT142개다.

첫 관찰은 encoder/top-k 단계의 낮은 IoU 대응이 decoder에서 크게 회복된다는 점이다. 초기 박스가 GT와 충분히 겹치지 않는다고 특징 정보가 사라졌다고 해석하면 안 된다. MAL도 seed별 top-k 대응 수의 차이가 크다. 이 표의 평균만으로 query 선택 모듈을 확정하지 않는다.

정확한 박스의 악화와 ranking 문제는 `query_transitions.csv`의 동일 query 전후 변화, `gt_stages.csv`의 best/leader 관계를 함께 분석해야 한다. encoder_all_counterfactual은 전체 격자에 bbox head를 추가 적용한 진단값이고 실제 런타임 출력 집합이 아니다. 최종 NMS는 score≥.001의 양수 크기 후보를 대상으로 한 내부 좌표 진단이다.

수정 loss 6개 학습 결과와 함께 다음 설계 판단에 사용할 자료다. 이번 기록은 아직 새 아키텍처의 효과를 입증하지 않는다.
