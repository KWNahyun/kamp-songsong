## 제2장 — AI 예측모델 개발 및 성능평가

### 2.1 연구 질문과 평가 방법

본 연구의 질문은 “작은 이물을 찾는 데 실패하는가, 아니면 찾은 후보의 경계와 점수를 정하는 데 실패하는가?”이다. 검출 성능 저하를 하나의 원인으로 가정하지 않고, 특징 해상도·후보 정렬·품질 점수의 영향을 순차적으로 비교하였다.

**용어와 분석 단위.** 정답 박스(Ground Truth; GT)는 공식 TXT의 위치·개수이다. 박스 겹침 비율(Intersection over Union; IoU)은 두 박스의 교집합 면적을 합집합 면적으로 나눈 값이다. 운영점 평가는 IoU 0.5에서 정답과 예측을 일대일 대응시켜 정검출(TP), 미탐(FN), 오검출(FP)을 센다. 재현율(Recall)은 TP/(TP+FN)이다. 평균 정밀도(AP)는 점수 순위에 따른 정밀도–재현율 관계를 요약하며, 본문 AP는 IoU 0.50부터 0.95까지 0.05 간격으로 평균한 COCO 지표를 100배한 값이다. AP75는 IoU 0.75에서 계산한다. 비최대 억제(Non-Maximum Suppression; NMS)는 겹치는 후보를 점수 순으로 줄이는 후처리이다.

**장비 명칭.** 데이터 파일의 M1·M2·M3는 각각 촬영 장비 **1호기·2호기·3호기**를 뜻한다. 이후 본문과 그림은 이 명칭을 사용한다. 장비 번호는 이물 종류나 위험 등급이 아니다. 장비별 차이는 제품 배치·촬영 조건·표본 구성과도 연결될 수 있으므로 장비 자체의 인과적 효과로 단정하지 않는다.


AP 계산에는 pycocotools의 기본 COCO 박스 평가(maxDets 100)를 사용했다. 고정 운영점의 TP/FP 및 FROC는 저장된 후보에 대해 점수 순 일대일 매칭으로 계산하므로 AP와 운영점 집계의 목적·후보 제한을 구분한다. 원본 픽셀 좌표로 복원한 박스를 평가하며, NMS 이전 저장 후보는 점수 0.001 이상에 제한된다.

본 연구는 동일한 전처리·촬영 그룹 분할·원본 좌표 평가에서 YOLOv8s와 D-FINE-S를 비교하였다. 학습 350장·정답 797개, 검증 66장·정답 144개를 사용하고 3개 seed로 반복하였다. COCO 기반 초기화, 640×640 여백 채움 변환(letterbox), 30 epoch 조건을 사용했으며 결과는 공통 NMS 0.7과 박스 배율 1.0에서 비교하였다. 3개 seed는 동일한 분할의 반복이며 독립 데이터셋 3개가 아니다. 재학습 시 정확한 가중치 일치보다 동일한 실험 조건과 반복 변동을 확인하는 데 목적을 두었다.

### 2.2 관찰에 따른 가설 검증

고해상도 특징이 작은 물체의 정보 보존에 유리하다는 선행연구(QueryDet; Yang et al., 2022)를 참고하였다. 다만 본 실험은 QueryDet 구현이 아니라, 기존 검출기에 stride 4의 고해상도 특징 경로(P2)를 추가한 통제 비교이다.

이물이 작다는 관찰에서 고해상도 P2 경로를 검증했지만 낮은 FP 조건까지 일관된 이득을 얻지 못했다. 후보 추적에서는 정밀한 후보의 존재와 최종 선택이 다른 문제임을 확인했다. 이에 감독을 MAL로 변경하고, 그 위에 quality 재점수화 UQ를 검증하였다. UQ의 detector와 bbox는 동결하여 좌표 개선과 score 효과를 분리하였다.

**표 1. 동일 후처리에서 검출기 및 핵심 구성 요소 비교.** 검증 66장·144개 정답, 동일 분할의 3개 난수 초기값(seed)에 대한 평균 ± 표본 표준편차이다. FP≤6 TP는 각 run의 검증 오검출 박스가 6개 이하인 운영점에서 검출한 정답 수이다.

| 모델 | AP | AP75 | FP≤6 TP/144 |
|---|---:|---:|---:|
| YOLOv8s | 38.75 ± 0.86 | 17.72 ± 1.69 | 137.33 ± 1.53 |
| YOLOv8s + 고해상도 경로 | 39.15 ± 0.80 | 19.49 ± 2.05 | 139.00 ± 1.00 |
| D-FINE-S | 38.68 ± 1.41 | 16.76 ± 0.71 | 140.33 ± 1.15 |
| D-FINE-S + 고해상도 경로 | 39.13 ± 0.63 | 18.51 ± 2.38 | 138.33 ± 2.89 |
| D-FINE-S + MAL | 38.36 ± 0.07 | 17.42 ± 2.03 | 141.67 ± 0.58 |
| D-FINE-S + MAL + UQ | 39.38 ± 0.62 | 19.05 ± 0.77 | 141.67 ± 0.58 |

표 1은 해상도 증가가 모든 평가 목적을 동시에 개선하지 않음을 보여준다. D-FINE의 고해상도 경로는 평균 AP를 높였지만 낮은 오검출 운영점의 검출 수는 감소했다. MAL 단독의 AP도 기본 D-FINE보다 높지 않다. 따라서 모든 추가 요소가 일관되게 성능을 높였다는 설명은 결과와 맞지 않는다.

![모델별 반복 실험 성능 비교](/home/viplab/contest/final_project/figures/figure_05_ablation.png)

**그림 2. 핵심 비교의 반복 변동.** 회색 점은 개별 run, 파란 마름모와 오차 막대는 3개 run의 평균과 표본 표준편차이다. 오차 막대는 신뢰구간이나 독립 데이터셋 간 변동이 아니다. 세 패널은 AP, AP75, FP≤6 조건의 검출 수를 각각 보여주며 축 범위가 다르다. MAL은 매칭 인지 손실, UQ는 아래에 정의한 후보별 품질 재점수화이다.

### 2.3 매칭 인지 손실과 후보 품질 재점수화

D-FINE은 박스 경계를 세분화된 분포로 표현하고 반복 정제한다(Peng et al., 2025). 본 연구는 DEIM의 매칭 인지 손실(Matchability-Aware Loss; MAL)을 적용했으며, DEIM 전체 학습 구성을 재현했다고 주장하지 않는다(Huang et al., 2025). 이후 정확한 박스 후보가 있어도 낮은 점수 때문에 선택되지 않는 현상을 대상으로 후보별 품질 예측(Unary Quality; UQ)을 추가하였다. 분포를 이용한 위치 품질 추정은 GFLv2 등 기존 연구와 연결된다(Li et al., 2021).

UQ는 최종 query 특징 256차원, 네 경계별 확률분포 상위 4개 값 및 그 4개 값의 평균을 합한 20차원, 기존 점수 1차원, 박스 중심·크기 및 로그 크기 6차원을 합한 283차원을 입력한다. 62,007개 학습 파라미터를 가진 경량 head이며, 검출기와 박스 좌표를 고정하고 학습한다. 목표는 각 후보와 정답 사이 최대 IoU이고, 품질 예측과 목표의 차이 제곱으로 가중한 이진 교차 엔트로피를 사용한다. 최종 점수는 기존 점수 p와 예측 품질 q의 기하평균 √(p·q)이다. q는 보정된 실패 확률이 아니다.

MAL 위에 UQ를 추가하면 AP가 평균 1.02점, AP75가 1.63점 증가했으나 FP≤6 검출 수와 지역 최고점수 query는 유지됐다. 따라서 효과는 주로 전역 점수 순위 개선으로 설명하며, 정밀 경계 복구나 모든 중복 후보의 대표 선택을 해결했다고 해석하지 않는다.

![최종 검출기와 후보 품질 보정 구조](/home/viplab/contest/final_project/figures/figure_07_method.png)

**그림 3. 두 단계 학습과 최종 추론 구조.** 먼저 MAL로 검출기를 학습하고, 이후 검출기를 고정하여 UQ만 학습한다. query는 검출기가 후보 하나를 표현하는 내부 특징 벡터이다. 경계 분포는 D-FINE의 세분화 분포 정제(Fine-grained Distribution Refinement; FDR) 출력이다. 최종 재점수화는 박스 좌표를 바꾸지 않지만 NMS의 처리 순서와 최종 선택은 바꿀 수 있다. 이 구조도는 실제 구현에 대응하며 별도 관계망이나 박스 정제 모듈을 포함하지 않는다.

### 2.4 후속 가설의 기각과 대표 모델 선정

상대 순위 감독·국소 픽셀 특징·경계 uncertainty 완화도 통제 비교했으나 최종 모델을 교체할 일관된 근거를 얻지 못했다. 마지막 Soft1+UQ는 같은 묶음 edge+UQ 대비 AP75 개선이1/3seed여서 사전 기준을 통과하지 못했다. 그 결과 기존 MAL+UQ를 유지하였다. 후속 ambiguity 묶음의 MAL 수치는 재현 변동이 있으므로 과거 MAL 수치와 직접 섞지 않는다.

단일 전달 checkpoint는 기존 MAL+UQ 3개 run의 검증 AP 중앙값에 해당하는 seed 20260930으로 정했다. 이는 최고 test 점수를 고르는 방식이 아니며, 대표 선정 규칙을 정한 시점은 2026-10-03이다. 아래 조건별 분석은 이 단일 모델을 대상으로 하며 표 1의 3개 run 평균과 구분한다.

고정 설정의 test 평가는 18개 run에 대해 이미 완료했다. MAL+UQ의 3개 seed 평균은 AP 37.46, AP50 93.29, AP75 15.88이며, 검증에서 정한 임계값에서 TP 196.33/206개·FP 16.00개였다. 이를 근거로 새 threshold를 선택하지 않았다. 팀원의 이전 전처리 선택에 test 사용 이력이 있고 후속 연구 시점에 test 결과를 이미 열람했으므로 완전한 untouched 독립 검증으로 표현하지 않는다.

**그림 4. 경계 완화 방법을 채택하지 않은 근거.** 동일 실험 묶음에서 Soft1+UQ와 edge+UQ의 차이를 같은 seed끼리 계산했다. 반복 1·2·3은 각각 20260929·20260930·20261001이다. edge는 좌표 손실을 좌·상·우·하 경계 표현으로 바꾼 대조군이고, Soft1은 여기에 원본 영상 1픽셀 수준 오차의 페널티를 완화한 방법이다. 평균 ΔAP75는 +0.59점이지만 두 반복에서 음수이며 한 반복의 +2.93점에 의존한다. 평균 개선과 반복 일관성은 다른 기준이다. 과거 MAL+UQ 결과를 이 paired 비교에 섞지 않았다.

### 2.5 연구 과정의 논리와 선행연구의 역할

**표 2. 관찰 → 가설 → 통제 비교 → 판단의 연결.** 각 행은 다음 실험이 필요했던 이유이며 단순 실행 목록이 아니다. 기각은 이번 자료·설정에서 채택 근거가 부족했다는 뜻이고 해당 아이디어 전체의 불가능성을 뜻하지 않는다.

| 관찰 | 검증한 가설 | 무엇을 비교했는가 | 결과 및 판단 |
|---|---|---|---|
| 정답 박스가 작음 | 해상도 손실이 주요 병목일 수 있음 | 두 검출기 각각 기본형 대 고해상도 경로, 3개 seed | AP와 낮은 FP 성과가 일관되지 않아 필수 구성에서 제외 |
| 정밀 후보의 존재와 선택 결과가 다름 | 감독 방식이 후보 품질을 개선할 수 있음 | D-FINE 대 동일 조건 MAL | 낮은 FP 검출 수는 개선했으나 AP는 감소; 목표별 효과 구분 |
| 점수와 위치 품질이 불일치 | 별도 품질 점수가 순위를 개선할 수 있음 | 같은 동결 검출기 대 UQ 추가 | AP +1.02, AP75 +1.63점; 낮은 FP TP는 동일 |
| UQ 후에도 지역 대표 선택이 정체 | 좋은 후보끼리의 순위 감독이 부족함 | 품질 손실 추가 학습 대 후보 쌍/목록 순위 감독 | MAL 계열 정밀 대표 수 평균 53.33개로 동일; 미채택 |
| 후보 특징만으로 경계 차이 구분이 어려움 | 주변 픽셀이 추가 단서를 제공할 수 있음 | 동일 파라미터 수의 대조군 대 국소 픽셀 입력 | 첫 seed에서 정밀 선택 개선 없음; 확대 보류 |
| 검은 점과 박스 여백 차이가 관찰됨 | 경계 불확실성 허용이 유리할 수 있음 | 경계 표현 대조군 대 1픽셀 완화, 각각 동일 UQ | AP75 개선 1/3 seed; 최종 교체 기준 미충족 |

후보 쌍 순위 감독(hard-pair)은 같은 정답에 대응하는 좋은 후보끼리 우열을 학습시키며, 목록 순위 감독(listwise)은 후보 집합의 순서를 학습시킨다. 정밀 대표 수는 근처 최고점수 후보가 IoU 0.75 이상인 정답 수이다. 국소 픽셀 비교는 단일 seed 선별 실험이므로 3개 seed로 검증한 결과처럼 표현하지 않는다.

**표 3. 선행연구와 실제 구현의 연결.** 논문 명칭은 새로 적용한 구성과 참고한 문제의식을 구분하기 위해 명시한다.

| 연구 | 핵심 아이디어와 이 연구에서의 연결 | 적용 범위와 차이 |
|---|---|---|
| QueryDet (Yang et al., 2022) | 고해상도 특징과 작은 물체 검출의 연결 | 고해상도 경로 가설의 근거; 희소 query 구조를 구현한 것은 아님 |
| D-FINE (Peng et al., 2025) | 경계 분포의 반복 정제와 위치 지식 자기증류 | 실제 기본 검출기; 원래 위치 품질 추정 기능이 있어 UQ를 최초 품질 추정 개념으로 주장하지 않음 |
| DEIM (Huang et al., 2025) | 다양한 매칭 품질을 다루는 MAL | MAL 손실만 적용; Dense O2O 등 전체 DEIM 구성과 구분 |
| GFLv2 (Li et al., 2021) | 박스 분포로부터 위치 품질을 추정 | UQ 입력 설계의 관련 근거; 이 논문의 검출기 전체를 복제하지 않음 |
| Rank-DETR (Pu et al., 2023) | 분류 점수와 위치 정확도 불일치를 순위 중심 설계로 다룸 | score–IoU 불일치 해석의 근거; matching/decoder를 해당 논문 방식으로 변경하지 않음 |
| TIDE (Bolya et al., 2020) | 검출 오류를 구분하여 성능 저하 요인을 진단 | 오류 분해 관점 참고; 본문 진단은 저장 후보 단계 기준이며 TIDE의 오류 기여도 계산과 다름 |
| Conformal risk control (Angelopoulos et al., 2024) | 별도 보정 자료를 활용한 위험 제어 | 현장 보정 절차의 관련 방법론; 본 자료에 통계적 위험 보장을 적용한 것은 아님 |

Rank-DETR가 지적한 점수–위치 불일치와 본 연구의 관찰은 연결되지만, UQ만으로 정밀 후보 선택이 해결되지 않았다는 결과도 함께 보존한다. 연구의 기여는 기존 문제를 새 개념으로 명명하는 데 있지 않고, 특정 X-ray 자료에서 가설의 적용 범위를 통제 비교로 좁힌 데 있다. [Rank-DETR 원문](https://arxiv.org/abs/2310.08854)

## 제3장 — 영향요인 및 오류분석

### 3.1 실패 단계의 정의

검출 오류를 분해해 원인을 구분한다는 관점은 TIDE와 연결되지만(Bolya et al., 2020), 아래 분류는 이 프로젝트의 후보 저장 단계에 맞춘 진단이며 TIDE 지표를 계산한 것은 아니다.


후보 부재, 경계 정렬, NMS 탈락, 임계값 탈락을 최종 FN 단계로 기록하고 ranking gap·duplicate·제품 경보를 보조 축으로 기록하였다. 제품 경보 유무는 단계별 실패 원인과 합산하지 않는다. 분석은 score floor.001 이후 저장된 후보 집합에 제한되므로 후보 부재를 곧바로 feature 부재로 해석하지 않는다.

**표 4. 미탐의 단계별 판정 규칙.** 최종 미탐 정답에 대해 위에서 아래 순서로 최초 해당 단계를 부여한다. IoU 0.3은 근처 후보 진단 기준이고 정검출 기준은 0.5이다. 기준값은 실패를 설명하기 위한 정의이며 물리적 결함 존재 판정이 아니다.

| 단계 | 저장 후보를 이용한 판정 | 해석 한계 |
|---|---|---|
| 근처 후보 부재 | NMS 이전 최대 IoU < 0.3 | 저장 기준 아래 후보나 내부 특징의 부재까지 증명하지 않음 |
| 경계 정렬 부족 | NMS 이전 최대 IoU가 0.3 이상·0.5 미만 | 위치 인접성과 공식 박스 정렬을 구분 |
| NMS 탈락 | 이전에는 IoU ≥ 0.5 후보가 있으나 이후 없음 | 억제 순서와 후보 중복의 영향 |
| 임계값 탈락 | NMS 이후 IoU ≥ 0.5 후보가 있으나 운영점 이후 없음 | 해당 후보의 점수가 기준 미달 |
| 일대일 대응 충돌 | 운영점 이후 적합 후보가 있으나 정답이 매칭되지 않음 | 가까운 복수 정답과 예측의 대응 관계 검토 필요 |

최대 IoU 후보와 최고점수 근처 후보의 IoU 차이는 **순위 불일치 보조 지표**로 별도 기록한다. 좋은 후보가 NMS에서 사라졌다면 순위 문제와 NMS 문제가 함께 관련될 수 있으므로 보조 축을 독립적인 추가 미탐 개수로 합산하지 않는다. 대표 모델의 최종 FN 2개는 모두 경계 정렬 부족에 속한다.

### 3.3 위치·대비·주변 밝기 변동의 사후 분석

원본 크기의 전처리 영상에서 정답 박스 내부 평균 밝기 μᵢ, 주변 영역 평균 μᵣ 및 표준편차 σᵣ를 계산하였다. 주변 영역은 박스에서 max(3, round(max(폭, 높이)/2))픽셀 확장한 창에서 모든 정답 박스 영역을 제외한 부분이다. 대비 대리지표는 |μᵢ−μᵣ|/(σᵣ+1)로 정의했다. 분모의 1은 8비트 밝기 단위의 안정화 상수이다. 이는 실제 물리적 밀도나 표준화된 장비 신호 대 잡음비 측정이 아니다. σᵣ 역시 질감·잡음·밝기 변화가 섞인 지표이다.

조건 구간은 학습 정답 797개의 3분위 경계로 정한 뒤 검증에 적용했다. 미탐 위치에 맞춰 경계를 탐색하지 않았지만, 이 분석 자체는 결과 확인 후 수행한 사후 분석이다. 정답 박스를 사용하는 대비·크기·위치 지표를 그대로 추론 시 재검사 입력으로 사용할 수는 없다.

## 제4장 — 판정 임계값·재검사·현장 활용

### 4.1 객체 검출과 제품 경보의 구분

임계값0.1933722943은 기존validation의 FP≤6 비교 운영점을 그대로 사용하였다. FROC는 threshold를 변화시킬 때 객체recall과 FP박스/영상의 관계를 보여준다. 대표seed는 낮은 threshold에서도2개 GT의 적합한 후보가 없어 recall이142/144에서 포화된다. 따라서 threshold를 낮추는 것만으로 이 두 localization FN을 복구할 수 없다. FROC를 근거로 새로운 threshold를 채택하지 않았다.

![임계값 변화에 따른 객체 재현율과 영상당 오검출](/home/viplab/contest/final_project/figures/figure_06_froc.png)

**그림 8. 대표 모델의 검증 FROC(Free-response Receiver Operating Characteristic).** 가로축은 영상당 오검출 박스 수, 세로축은 객체 재현율이다. 왼쪽은 저장 후보 범위 전체, 오른쪽은 낮은 오검출 영역을 확대했다. 빨간 점은 고정 운영점 FP 6/66장, TP 142/144개이다. 곡선은 기존 예측 점수를 변화시켜 계산한 설명 자료이며 새로운 임계값 선정에 사용하지 않았다. 정상 제품의 오경보 확률을 나타내는 ROC와는 다르다.

Test3seed 평균 FP/영상은16/84≈.190으로 val6/66≈.091과 달랐다. FP박스/영상은 정상 제품의 오경보 확률이 아니다. 현장에서는 모델·전처리를 먼저 고정한 뒤 목표장비/제품의 정상·불량 calibration 자료를 확보하고 허용할 제품 통과 위험을 정의해야 한다. 위험 조건을 만족하는 threshold 후보에서 검사 부담을 비교하고 독립 촬영 그룹으로 검증한다. 현재반복 사용val은 새 calibration 자료를 대체하지 못한다.

**그림 9. 저장된 검증·test 결과에서 서로 다른 운영 지표의 비교.** 각 막대는 기존 MAL과 MAL+UQ의 3개 seed 평균이다. 검증은 66장·144개 정답, test는 84장·206개 정답이다. 각 run의 검증 임계값을 test에도 고정 적용한 기존 결과를 재표현했으며 재추론하거나 임계값을 바꾸지 않았다. 양성 영상 경보는 해당 영상에 경보 박스가 하나라도 있는지를 뜻하며 모든 이물을 정밀하게 찾았다는 뜻이 아니다. 제품 식별의 추가 근거가 없는 경우 영상 단위 경보를 제품 단위 평가의 대리로 사용한다.

MAL+UQ의 test AP가 개선되어도 고정 임계값 FP는 MAL의 평균 11.33개에서 16.00개로 증가한다. 따라서 품질 점수의 장점은 AP 개선으로 한정하고 현장 오경보 감소까지 확장하지 않는다. 현재 데이터에서 경보율 100%는 불량 제품 영상에 대한 결과이며 정상 제품 특이도를 제공하지 않는다.

### 4.2 현장 임계값을 정하는 절차

실제 적용 시에는 (1) 정상·불량 및 촬영 장비·제품 조건을 포함한 별도 보정 자료 확보, (2) 허용할 미탐 위험과 검토 용량 정의, (3) 임계값별 객체 재현율·영상당 FP·제품 통과 오류 산출, (4) 위험 조건을 만족하는 범위 안에서 부담 비교, (5) 새로운 촬영 그룹에서 고정 설정 검증 순으로 진행한다. 이는 현장 적용 제안이며 현재 자료만으로 완성한 절차가 아니다. 특히 불량 제품이 무경보로 통과하는 위험과 한 영상 속 이물 한 개의 위치 미탐은 서로 다른 손실로 정의해야 한다.

별도 보정 자료에서 위험을 제한하는 방법론은 conformal risk control과도 연결된다(Angelopoulos et al., 2024). 그러나 본 연구가 그 절차를 구현하거나 통계적 안전 보장을 얻은 것은 아니다. 반복 사용한 검증 자료와 정상 자료 부재를 고려하면, 본 결과는 현장 보정 절차의 제안 수준이다.

### 4.3 재검사 우선순위의 기존 검증과 한계

재검사는 영상/제품 단위로 넘기고 후보박스는 사유를 설명하는 데 쓴다. 기존 낮은 신뢰도·YOLO불일치·개수차이는 작은val에서 무작위 검토보다 안정적으로 좋다는 근거를 얻지 못했다. 이를 효과가 검증된 정책으로 제시하지 않는다. 입력계약 위반, 후보 위치/크기 불안정 등 소수의 원인별 규칙은 향후 검토 후보이며 이들에 대한 새 효과 검증은 아직 하지 않았다. UQ는 IoU quality target이지 calibrated failure probability가 아니다.

5/10/20% 검토 예산은66장 기준4/7/14장(실제6.1/10.6/21.2%)으로 기록하고, 목록에 포함된 FN객체·FN영상, 비검토 목록의 잔여FN, 무작위 대조와 동점 변동을 함께 보고한다. 실제 사람이 검토해 찾아냈다는 증거 없이 '미탐 회수율'이라고 쓰지 않고 '미탐 포함률'로 표현한다.

기존 분석은 두 검출기의 점수 0.25 이상 후보로 신호를 계산했다. 이 0.25는 신호 계산용 기준이며 최종 검출 운영 임계값과 다르다. 낮은 점수 신호는 후보 최저 점수의 역수준(1−최저 점수), 박스 불일치는 일대일 대응된 박스 IoU 합을 더 많은 후보 수로 나눈 값의 보수, 개수 차이는 두 검출기의 후보 수 차이의 절댓값이다. 후보가 없을 때의 처리와 동점 순서는 코드에 고정했다. 서로 다른 검출기의 점수가 같은 확률 의미를 가진다는 보장은 없어 이 정의도 탐색적 한계에 포함된다.

![기존 재검사 우선순위와 무작위 검토 비교](/home/viplab/contest/final_project/figures/figure_10_review.png)

**그림 10. 검토 목록에 포함된 미탐 수와 무작위 대조.** 각 패널은 동일 검증 66장에 대한 별도 seed이며 전체 미탐은 각각 3·2·2개이다. 가로축은 실제 4·7·14장 검토 비율이다. 점선과 회색 영역은 같은 수의 영상을 무작위로 선택한 기존 10,000회 모의 추출의 평균과 2.5–97.5백분위 범위이다. 이는 모형 성능의 신뢰구간이 아니다. 색 곡선은 고정 신호 순위로 고른 목록의 미탐 포함 수이며 실제 작업자의 재검사 성공을 측정하지 않았다. 연결선은 이산 예산점의 읽기를 돕기 위한 것이다.

**표 8. 검토 예산별 미탐 포함 수의 3개 seed 평균.** 분모는 66장으로 동일하고, 전체 미탐 수는 seed별로 다르다. 아래 값은 미탐 개수 평균이며 비율 평균이 아니다.

| 검토 영상 수 (실제 비율) | 낮은 후보 점수 | 검출기 박스 불일치 | 검출 개수 차이 | 무작위 평균 |
|---|---:|---:|---:|---:|
| 4장 (6.1%) | 0.67 | 0.00 | 0.00 | 0.149 |
| 7장 (10.6%) | 0.67 | 0.33 | 0.00 | 0.257 |
| 14장 (21.2%) | 1.00 | 0.67 | 0.00 | 0.502 |

낮은 후보 점수는 평균상 무작위보다 높지만 반복 2의 작은 예산에서는 한 개도 포함하지 못한다. 작은 미탐 수와 넓은 무작위 변동을 고려하여 안정적으로 우월한 정책이라고 결론 내리지 않는다. 개수 차이는 동점이 많아 영상 ID로 정한 순서에 결과가 크게 의존한다. 동점 범위는 원본 CSV에 별도로 보존했고, 평균 0개라는 결과로 신호의 모든 가능성을 부정하지 않는다.

검토 목록 R에서 미탐 포함률은 `R 안의 FN / 전체 FN`, 비검토 잔여 미탐은 `전체 FN − R 안의 FN`으로 보고한다. 실제 회수율은 작업자가 새로 확인한 이물 수를 따로 측정해야 한다. 검토하지 않는 비율(coverage)과 그 안의 오류(selective risk)를 표시할 수는 있지만 정상 제품 없는 현재 자료로 자동 통과 정책의 위험을 추정해서는 안 된다.

### 4.4 조건 지표의 사용 범위와 산업 적용 제안

**표 9. 사후 설명과 추론 시 판단 신호의 구분.** 같은 이름의 지표도 정답 박스로 계산하면 추론 입력으로 사용할 수 없다.

| 구분 | 사용할 수 있는 항목 | 현재 근거 |
|---|---|---|
| 정답 기반 사후 설명 | 공식 박스 크기·중심·종횡비·정답 영역 대비·정답 개수 | 조건별 성능 분석 완료; 실제 크기·형상·밀도의 직접 측정이 아님 |
| 추론 가능한 출력 | 예측 점수·UQ 품질·예측 박스 중첩/분산·두 모델 불일치 | 일부 단순 신호 검토 완료; 나머지는 효과 미검증 |
| 입력/설비 메타정보 | 해상도·장비·촬영일·입력 형식 | 운영 로그로 기록 가능; 약한 장비라는 이유만으로 위험 확정 불가 |
| 현재 분석 불가능 | 물리적 밀도·재질별 성능, 실제 제품 경계 거리, 정상 오경보율 | 대응 라벨·제품 경계 또는 정상 표본 부족 |

새로운 가중합 위험 점수를 작은 validation에 맞추기보다는, 재검사 사유가 설명되는 규칙을 향후 검증 대상으로 제시한다. 입력 계약 위반은 모델 성능 점수가 아니라 입력 오류로 처리하고, 정상 입력의 무검출·불안정 후보는 자동 통과 승인이 아닌 확인 대상 상태로 남긴다. 후보 분산 등이 실제로 미탐을 선별하는지는 별도 자료에서 검증해야 한다.

제안 흐름은 **X-ray 입력 → 입력품질 확인 → 고정 detector → 경보/검토 사유 표시 → 작업자 격리·확인·재촬영 → 확인 결과 기록**이다. 무검출 영상을 자동 정상으로 승인하지 않는다. 제품 자동배제의 비용/라인속도/재검사시간은 실제 현장 요구를 받아 정해야 하며 본 자료로 검증된 수치가 아니다.

Synthetic 팀에는 동일PNG/TXT 형식 외에 이 checkpoint,640변환,NMS,고정threshold,score해석과 박스 경계규칙을 전달한다. 조건별score/IoU/검출/검토사유를 기록하되 synthetic의 실제크기·재질변화는 real 데이터에서 관찰한 성능과 분리한다. Tight synthetic box와 여백 있는 real box의 차이가 metric에 미치는 영향도 명시한다.

### 4.5 촬영 그룹을 제외한 임계값 전이 실험

대표 단일 checkpoint를 고정하고 검증의 11개 촬영 그룹을 하나씩 제외했다. 나머지 10개 그룹에서 임계값을 정하고 제외한 그룹에 적용했다. 제외한 그룹의 정답으로 해당 임계값을 고르지 않았다. 다만 이 validation은 이미 모델 개발에 반복 사용했으므로 독립 외부 평가나 이론적 위험 보장으로 해석하지 않는다. Test 결과·영상은 이번 분석에서 읽지 않았다.

비교 규칙은 사전에 분석 설정 파일에 기록했다. 오검출 예산 방식은 보정 자료에서 FP/영상 ≤0.1인 가장 낮은 저장 점수, 목표 재현율 방식은 전체 정답 재현율 ≥95% 또는 ≥98%를 만족하는 가장 높은 점수를 선택했다. 그룹별 방식은 보정 자료의 모든 그룹이 각각 재현율 ≥95%를 만족하는지 확인했다. 목표를 충족하는 후보가 없으면 **해당 fold의 정책을 정의할 수 없음**으로 처리한다. 코드에 남긴 최저 점수까지의 결과는 불가능성 확인용 진단이며 채택 가능한 안전 대안이 아니다.

**표 10. 제외 그룹에 적용한 운영점 결과.** 각 영상은 제외 그룹 평가에 한 번만 포함되며 합계 분모는 66장·144개 정답이다. 이는 대표 단일 seed 결과이며 3개 seed 평균이 아니다.

| 보정 규칙 | 제외 그룹 TP / 144 | FN | FP | FP/영상 | 전체 재현율 | 보정 목표 불가능 fold |
|---|---:|---:|---:|---:|---:|---:|
| 오검출 예산 ≤0.1/영상 | 142 | 2 | 7 | 0.106 | 98.61% | 0/11 |
| 전체 재현율 ≥95% | 135 | 9 | 2 | 0.030 | 93.75% | 0/11 |
| 전체 재현율 ≥98% | 140 | 4 | 2 | 0.030 | 97.22% | 0/11 |
| 각 보정 그룹 재현율 ≥95% | — | — | — | — | — | 10/11 |

오검출 예산 방식의 임계값은 0.1856~0.1934였고, 제외 그룹 합계에서도 기존 검출 수 142개를 유지했으나 FP는 기존 6개에서 7개로 늘었다. 목표 재현율 방식은 보정 자료에서는 조건을 만족해도 제외 그룹에서는 전체 목표를 달성하지 못했다. 따라서 표본 평균에 맞춘 수치를 현장 보장값으로 해석할 수 없다.

그룹별 목표 방식은 대부분의 보정 fold에서 적합한 후보 자체가 부족해 성립하지 않았다. 유일하게 보정 목표를 만족한 fold에서도 제외 그룹 결과는 0/2개였다. 그 그룹은 3호기 2020-07-27 촬영 자료로 정답이 2개뿐이다. 이 결과는 취약 조건을 경고하지만 큰 모집단의 장비별 위험을 정밀하게 추정한 수치는 아니다.

![촬영 그룹 간 임계값 전이 결과](/home/viplab/contest/final_project/figures/figure_11_group_transfer.png)

**그림 11. 임계값 규칙의 촬영 그룹 전이와 성립 가능성.** 왼쪽은 보정 목표를 만족한 fold만 표시하며 점 하나는 제외 그룹 하나이다. 서로 같은 결과는 겹친다. 오른쪽은 11개 fold 중 보정 단계에서 목표를 만족하지 못한 수이다. ‘fold’는 한 촬영 그룹을 제외해 평가하는 1회의 분할을 뜻한다. 각 그룹 표본 수가 달라 작은 그룹의 0%·50%를 큰 그룹과 동일한 확신으로 해석하지 않는다.

Learn then Test와 Conformal Risk Control은 예측 모델과 별도로 판정 규칙을 보정하는 관련 방법론이다. 본 실험은 그 이론 보장을 구현한 것이 아니라 단순 규칙의 그룹 간 전이를 비교한 것이다. 군집 의존성과 validation 선택 이력을 고려하면 새로운 독립 촬영 자료가 필요하다. [Learn then Test](https://arxiv.org/abs/2110.01052)

### 4.6 탐지 박스와 작업자 검토 영역의 분리

공식 AP에 사용하는 탐지 박스는 바꾸지 않고, 기존 고정 임계값을 통과한 예측 박스에 원본 영상 기준 0·1·2·4·8픽셀 여백을 더해 별도의 검토 영역을 구성했다. 영상 바깥은 자르고 겹치는 면적은 합집합으로 계산했다. 영역 생성에는 정답을 사용하지 않았다. 정답 박스와의 겹침은 이후 평가에만 사용한다.

정답 면적 포함도는 `정답 박스와 검토 영역 합집합의 교집합 면적 / 정답 박스 면적`이다. 연속 좌표의 사각형 합집합 면적을 계산하여 작은 박스의 픽셀 반올림 오차를 피했다. 표시 부담은 영상별 합집합 면적/영상 면적으로 요약했다. 일대일 대응을 강제하지 않으므로 한 영역이 여러 정답을 포함할 수 있으며, 이 지표를 객체 검출 Recall이나 AP로 부르지 않는다.

**표 11. 검토 영역 확장에 따른 공식 정답 영역 포함과 화면 면적.** 대표 모델, 검증 66장·144개 정답, 고정 임계값 기준이다. 표시 영역 수는 평균 2.24개/영상으로 유지하며 영역의 크기만 바꾼 비교이다.

|---|---:|---:|---:|---:|---:|
| 0픽셀 | 144 | 45 | 22 | 0.176% | 0.334% |
| 1픽셀 | 144 | 105 | 78 | 0.250% | 0.469% |

| 4픽셀 | 144 | 143 | 143 | 0.549% | 1.011% |

대표 FN110은 기존 검토 영역이 정답 면적의 약35.0%를 덮고 중심은 포함한다. 여백 4픽셀에서도 약80.7%이며 8픽셀에서 전체를 포함한다. 반면 FN136은 기존 박스가 정답 면적의 약95.1%를 덮고도 검출 IoU 0.5에는 못 미친다. 이는 큰 예측 박스의 포함도와 위치 정밀도가 서로 다른 질문에 답한다는 구체적 사례이다. 검토 포함도를 이용해 기존 FN을 TP로 재분류하지 않는다.

![작업자 검토 영역의 포함도와 표시 부담](/home/viplab/contest/final_project/figures/figure_12_review_regions.png)

**그림 12. 검토 표시의 기하학적 이득과 부담.** 왼쪽은 정답 중심·면적 포함 개수, 오른쪽은 영상별 표시 면적 비율의 평균과 95백분위이다. 백분위는 신뢰구간이 아니다. 실제 결함 분할 라벨이 없으므로 공식 TXT 영역을 대상으로 한 분석이고 물리적 결함 전체 포함의 증명은 아니다. 정상 영상과 작업자 실험 없이 검사 시간 절감·불량 회수·정상 오경보 감소를 주장하지 않는다.

철도 신호 검출의 conformal 적용(Andeol et al., 2023)은 검출의 불확실성을 출력 영역과 연결하는 관련 사례이다. 다만 본 실험의 고정 픽셀 여백 비교는 conformal 보장을 갖는 영역을 산출한 것이 아니다. 실제로 적용하려면 새로운 보정 자료에서 영역 크기와 허용 부담을 정하고 별도 자료에서 평가해야 한다.

### 4.7 다른 검출기의 추가 검토 가능성

같은 seed의 기존 YOLOv8s 예측을 사용해 D-FINE+MAL+UQ의 미탐을 보완할 수 있는지 확인했다. 기존 고정 운영점의 D-FINE TP는142개, YOLO TP는136개이며 둘 중 하나라도 일대일 매칭에 성공한 정답의 합집합은142개였다. D-FINE의 FN110·136에 대한 YOLO 저장 후보 최대 IoU는 각각0.322·0.410으로, YOLO 임계값을 낮춰도 저장 후보 내에는 IoU0.5를 만족하는 보완 박스가 없다.

따라서 **이 대표 run에서는 YOLO 추가 확인으로 공식 정답 기준 미탐을 회수할 근거가 없다.** 두 모델 정답 집합의 합집합은 정답을 이용한 진단용 상한이며 실제 결합 검출기 성능이 아니다. 다른 seed와 새로운 촬영 자료까지 일반화하지 않으며, 이 결과를 근거로 새로운 앙상블을 학습하거나 최종 모델을 교체하지 않았다.

추가 운영 분석의 결론은 세 가지이다. 기존 오검출 예산 방식은 탐색적 전이 비교에서 검출 수를 유지했지만 운영 보장은 아니다. 검토 영역은 경계 주변을 보여주는 정도를 개선할 수 있지만 실제 이물 회수를 뜻하지 않는다. 다른 검출기의 출력이 남은 오류를 반드시 보완하지는 않는다. 실제 사람 확인 실험은 이러한 한계를 설명한 뒤 진행해야 하며 현재 완료한 것으로 기재하지 않는다.

### 4.8 검사 보조 화면과 사람 검토 비교 설계

NMS와 고정 임계값 적용 후 남은 탐지 박스를 전처리 영상 위에 표시하는 검사 보조 화면을 구현하였다. 탐지 박스는 주황색, 작업자가 확인할 2픽셀 여백은 청록색으로 구분한다. 여백은 공식 평가 박스나 모델 출력을 변경하지 않는다. 탐지가 없을 때는 ‘무검출’로 표시하며 정상 자동 통과로 해석하지 않는다.

![검사 보조 화면 예시](/home/viplab/contest/final_project/figures/figure_13_review_interface.png)

**그림 13. 구현된 검사 보조 화면의 미리보기.** 작은 의심 위치를 확대된 영상에서 확인하고 위치 클릭을 기록할 수 있다. 화면의 박스는 고정 모델의 실제 validation 예측이다. 이 그림은 인터페이스 구현 예시이며 사람 검토의 효과를 측정한 결과가 아니다.

검토 효과는 전처리 영상만 표시, 탐지 박스 표시, 탐지 박스와 2픽셀 여백 표시의 세 조건으로 비교하도록 설계하였다. 참가자별 66장을 각 조건22장씩 배정하며 같은 영상을 반복 제시하지 않는다. A/B/C 배정군 간에는 같은 영상의 표시 조건을 순환시킨다. 참가자에게 공식 정답과 정답 개수를 공개하지 않으며 사전 데이터 열람 여부를 기록한다. 창 전환 시간은 제외하고 실제 활성 화면 시간을 저장한다.

주요 측정값은 공식 TXT 박스 안의 클릭을 일대일 대응한 위치 표시 성공률, 정답과 대응되지 않은 클릭 수, 영상별 활성 검토 시간이다. 박스가 넓으면 클릭이 우연히 포함될 수 있으므로 물리적 이물 경계 정확도나 detector AP로 해석하지 않는다. 참가자별 조건 차이를 먼저 보고하며 촬영 그룹 의존성을 무시한 독립 표본 신뢰구간을 제시하지 않는다. 배정군·검사 경험·사전 노출 차이와 유사 촬영의 기억효과를 함께 검토해야 한다.

**현재 상태는 도구 및 프로토콜 준비 완료이고 사람 실험 결과는 없다.** 모든 영상이 이물 포함 제품이므로 정상 판별, 공장 작업자 성능, 안전한 자동 통과 또는 실제 미탐 회수를 입증하는 실험이 아니다. 팀원 참여 결과가 확보되면 소규모 검사 보조 가능성 평가로만 보고한다.

## 제5장 — 창의성 및 차별성

### 5.1 기여와 주장 범위

차별점은 검출기를 복잡하게 확장한 것이 아니라 **관측된 실패 단계에 따라 가설을 좁히고, 동일 조건의 대조군으로 효과를 확인한 과정**에 있다. P2의 불일치, MAL의 후보 유지, UQ의 전역AP 개선과 지역선택 정체, ambiguity 감독의 제한적 이득을 구분했다. 부정적 결과도 추가모델 탐색을 중단하는 근거로 사용했다.

UQ는 final query·FDR분포 top4와 평균·기존score·bbox기하를 입력하는62,007parameter head로, candidate와GT의 최대IoU를 학습하며 최종score는sqrt(base×quality)다. D-FINE/GFLv2 등의 quality-aware scoring과 문제의식이 겹치므로 완전히 새로운 검출 개념으로 주장하지 않는다. 동일 이물의 여러후보를 동시에 높게 평가할 수 있는 target이어서 duplicate 대표선택을 직접 감독한 구조도 아니다.

경계 표기 비일관성은 시각적으로 관찰했지만 annotation error rate를 측정한 것은 아니다. 공식TXT를 competition truth로 유지했고, 실제 이물 경계·촬영변동·label convention·공통모델편향을 분리해 해석했다. 기여는 '안전보장'이 아니라 검출성과와 남은 불확실성을 검사판단으로 연결할 근거를 정리한 것이다.

**표 12. 본 연구의 기여와 과장하지 않는 경계.** 대회에서 설명할 수 있는 실증적 기여와 새로운 일반 이론·안전성 보장을 구분한다.

| 주장 가능한 기여 | 대응 근거 | 주장하지 않는 내용 |
|---|---|---|
| 실패 단계에 따라 실험 방향을 수정 | 해상도·MAL·UQ·순위·국소 특징·경계 완화의 통제 비교 | 모든 작은 이물 데이터에 동일한 병목이 존재 |
| 후보 품질 재점수화의 실측 효과 | 동일 동결 검출기에서 AP/AP75 상승 | 품질 추정이라는 개념의 최초 제안, 미탐 완전 해결 |

### 5.2 일반화의 한계

주요 한계는 양성 제품 중심 자료, 반복 촬영과 제한된 조건 범위, validation 반복 활용, 작은 미탐 표본, 과거 test 활용 이력이다. 후보 최대 IoU는 정답을 사용하는 사후 진단이며 실제 달성 성능이 아니다. synthetic의 조건 제어는 이 한계를 탐색할 수 있지만 실제 정상·불량 제품의 독립 평가를 대체하지 않는다. 따라서 이 보고서는 모델 점수와 함께 **확인한 사실·남은 가설·필요한 현장 자료**를 구분한다.

`final_project`에 vendor D-FINE source, UQ,고정checkpoint/config,manifest,추론/평가,기존val결과,분석CSV/그림,환경lock을 분리했다. 제공 처리본을 입력해 전체val을 다시 추론한 결과 기존NMS후13256개prediction의좌표/score가 전부 같았고 AP39.275808/AP7519.660062/TP142/FP6을 재현했다. 평가기는 파일명으로ID를 맞추고 팀원COCO category1과 실험category0을 명시적으로 처리한다. 추론은GT를 읽지 않는다.

설정/자료/소스의 재현성과 재학습의bitwise결정성을 구분한다. 기존감사에서CUDA grid_sample backward 비결정성을 확인했으므로 seed고정만으로 같은가중치를 보장하지 않는다. 고정checkpoint·prediction·metric재현을 제공하고 재학습변동은3seed결과로 별도기록한다. 원본자료와실험폴더는보존하며 제출코드의출처와라이선스를 유지한다.

| UQ 학습 진입점 | 2배치 head 갱신과 detector 불변 검사 | 통과; 최종 모델 교체 없음 |
| 고정 모델 추론·평가 | 새 가상환경에서 66장·13,256개 예측 비교 | 좌표·점수·metric 일치 |
| 전체 재학습 | 30+30 epoch 후 반복 변동 확인 | 이번 패키지 감사에서 미실행 |
| 원본 BMP 전처리 연결 | 팀원 구현 및 설정 연결 | 사용자가 마지막에 통합 |
| 다른 컴퓨터·GPU | 별도 하드웨어 이식 확인 | 미검증 |

재현 패키지의 실제 실행 안내는 README에 유지한다. 제출 시 데이터·가중치·실험용 임시 출력의 범위를 구분하고 원출처·라이선스·설정 해시를 보존한다. 환경 설치에 로컬 캐시를 사용한 것은 기존 가상환경의 site-packages를 상속한 것과 다르며, 검증 환경은 별도 생성했다.

### 6.2 공식 요구사항과 근거 자료의 대응

**표 14. 사용자 담당 범위의 요구사항 대응.** 공식 과제문·양식 및 사용자가 전달한 추가 공지를 기준으로 본문과 증거를 연결했다. 형식상 항목이 존재하는 것과 현장 안전성이 검증된 것은 구분한다.

| 요구사항 | 본문 및 근거 | 남은 연결 또는 한계 |
|---|---|---|
| 두 가지 이상 모델 비교·최종 선정 | 제2장, YOLOv8s/D-FINE 비교 및 반복 성능표 | 대표 모델은 검증 중앙값 run, test 최댓값 선정 아님 |
| 이물 탐지와 위치 표시 | 실제 성공·실패 영상, 고정 추론 overlay | TXT를 공식 정답으로 유지 |
| 조건별 성능·미탐 분석 | 제3장, 장비·박스 크기·위치·대비 분석 | 물리적 형상·밀도는 자료 부족 |
| 임계값·재검사 기준 | 제4장, FROC·무작위 검토 대조·현장 보정 절차 | 안전 임계값이나 실제 회수율 확립 아님 |
| 산업 활용·차별성 | 제4~5장, 판단 흐름과 가설별 채택/기각 | 정상 제품·실제 작업자 검토 필요 |
| 코드와 재현성 | 제6장, README·환경·검증 JSON·고정 checkpoint | 원본 전처리 연결은 마지막 사용자 작업 |
| 전처리 방법과 영향 명시 | 데이터 담당 본문과 연결 | 본 보고서에서 팀원의 데이터 분석을 대신 작성하지 않음 |

수치 검토 기록은 [보고서 감사 JSON](/home/viplab/contest/final_project/analysis/report_audit.json)에 보존했다. 기본 모델 비교는 `experiments/kamp_v2_baselines/analysis/metrics.csv`, MAL/UQ는 `experiments/kamp_v2_uq/analysis/metrics.csv`, 경계 완화 paired 비교는 `experiments/kamp_v2_ambiguity_uq/analysis/paired_UQ.csv`, 재검사 분석은 `experiments/kamp_v2_reinspection/review_curves.csv`를 근거로 한다. 그림 재생성 원자료의 경로와 해시는 패키지의 `analysis/synthesis_sources.json`에 기록했다.

### 6.3 코드·가중치 출처와 전달 파일 관리

D-FINE 원본 소스의 저작권과 Apache 라이선스를 유지하고, DEIM의 MAL을 적용한 패치에는 원출처 및 변경 목적을 별도로 기재했다. 프로젝트의 UQ·실행 래퍼·보고서 생성 코드는 원래 검출기 소스와 분리했다. 단일 클래스 초기 가중치는 공식 COCO 가중치의 호환 tensor를 불러와 생성한 파일이며 최종 KAMP 학습 가중치와 구분한다.

기존 고정 test 예측은 대표 모델의 저장 결과를 변경 없이 전달용 경로로 복사했다. 원본 좌표계·image_id 대응·점수 기준·후처리·해시를 함께 보존하며, 이 복사 과정에서 test를 재평가하거나 모델을 선택하지 않았다. 점검용 smoke checkpoint와 중복 출력은 실제 전달 후보와 구분했다. 데이터 공개 재배포 권한을 코드 라이선스와 동일시하지 않으며, 현재 패키지는 공개 배포가 아닌 로컬 재현 자료이다.
