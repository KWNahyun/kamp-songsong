# X-ray 검사 보조 화면과 검토 비교

이 폴더는 준비된 화면이다. 실제 사람 검토 효과는 아직 측정하지 않았다.

- `inspector.html`: 사용자·분석 담당자용 미리보기. 영상과 표시 방식을 자유롭게 바꾼다. 실험 참가자에게 미리 보여주지 않는다.
- `study.html`: 참가자용 비교 화면. 66장 중 전처리 영상만/탐지 박스/박스+2픽셀 여백을 각각22장 제시한다. 같은 참가자에게 같은 영상은 한 번만 제시한다.
- `protocol.json`: 고정된 비교 조건과 평가 항목. 여백2픽셀은 비교용 설정이지 안전성 검증을 마친 운영값이 아니다.

## 실행

이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/inspector.html` 또는 `study.html`을 연다. 현재 작업에서 로컬 서버를 실행해 두었다. 서버가 종료되면 이 명령으로 다시 시작한다. HTML에 영상이 포함돼 있으며 외부 통신은 하지 않는다.

## 비교 실험 절차

1. 담당자가 참가자에게 익명 ID와 A/B/C를 배정한다. 가능하면 서로 다른 참가자 3명 이상을 세 군에 균형 배정한다. 한 사람이 ID를 바꿔 여러 군을 반복하지 않는다.
2. 데이터나 정답을 본 이력이 있으면 체크한다. 같은 실험을 이미 수행했거나 결과를 알고 있는 참가자의 결과는 독립적인 처음 보는 검토로 보고하지 않는다.
3. 참가자는 의심되는 점의 중심을 클릭하고 완료한다. 정답·정답 개수는 표시하지 않는다. 아무 위치도 표시하지 못하면 체크 후 진행한다. 되돌아가 수정하는 기능은 없다.
4. 실제 화면이 활성화된 시간을 기록한다. 탭 전환/창 이탈은 일시 정지한다. 영상 로딩 시간은 활성 검토 시간에 넣지 않는다. 새로고침하면 완료된 사례까지만 복원하고 미완료 사례 기록은 초기화된다.
5. 종료 후 JSON을 다운로드해 분석 담당자에게 전달한다. 참가자당 최종 누적 파일 한 개만 사용한다. 브라우저 데이터를 지우면 진행 이력이 사라질 수 있으므로 중간에도 저장한다.

초기 운영 안내는 모두에게 동일하게 제공한다. 검사 경험·모니터·확대 배율 등의 차이를 기록하고, 검토 중 참가자 간 답을 공유하지 않는다. 모든 자료가 이물 포함 영상이며 정상 판별 성능을 측정하지 않는다. 촬영이 유사한 영상이 있어 같은 파일을 반복하지 않아도 기억효과가 남을 수 있다.

## 분석

패키지 루트에서 다음을 실행한다.

```
python scripts/score_review_study.py --results /path/review_personA.json /path/review_personB.json --output outputs/human_review_results
```

출력은 참가자·조건별 공식 TXT 내부 위치 표시 성공률, 미대응 클릭 수, 활성 확인 시간이다. 정답 박스 안의 클릭을 일대일 대응하므로 여러 번 찍어도 정답 하나는 한 번만 센다. 이것은 물리적 이물의 실제 중심 확인이나 detector AP와 같지 않다. 결과를 내기 전 정답 박스가 넓어 우연히 포함되는 문제와 경계 불확실성을 함께 해석한다.

정답 키는 `../analysis/review_study_admin/answer_key.json`에 별도 보관한다. 참가자에게 이 폴더 밖의 정답 키를 전달하지 않는다. UI에서 정답을 숨긴 것이며 의도적인 데이터 추출을 막는 보안 시험은 아니다.

원영상 조건은 **팀원이 전처리한 입력 영상만 표시**하는 조건이다. 색상 마커가 있는 raw BMP를 뜻하지 않는다. 미리보기 또는 자동화 점검 기록은 사람 실험에 넣지 않는다. 공장 작업자나 정상 제품을 포함한 검증이 아니므로 산업 안전성·자동 통과·실제 미탐 회수를 입증하지 않는다.
