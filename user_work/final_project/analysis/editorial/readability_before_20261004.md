## 제2장 — AI 예측모델 개발 및 성능평가

> **핵심 결론:** 작은 이물을 위한 고해상도 경로보다, 후보 박스의 위치 품질과 점수 순위를 다루는 접근이 최종 선정에 기여했다. D-FINE-S에 MAL과 UQ를 결합한 구성을 유지했으며, UQ는 MAL 대비 AP를 1.02점, AP75를 1.63점 높였다. 낮은 오검출 조건의 검출 수는 유지되어, UQ의 효과는 주로 **점수 순위 개선**으로 해석한다.

### 2.1 연구 질문과 평가 설정

**핵심 질문은 “이물을 찾지 못하는가, 찾은 후보의 경계와 점수가 부정확한가?”이다.** 이를 구분하기 위해 두 검출기를 같은 데이터와 평가 조건에서 비교하고, 후보 박스가 최종 출력까지 유지되는 과정을 추적했다.

학습셋은 350장·정답 797개, 검증셋(validation)은 66장·정답 144개이다. 촬영 그룹 분할을 고정하고 세 난수 초기값(seed)으로 실험을 반복했다. 공통 설정은 COCO 기반 초기화, 640×640 여백 채움 변환, 30회 전체 학습(epoch), NMS 0.7, 박스 배율 1.0이다. 반복 결과는 평균과 표본 표준편차로 제시한다.

**평가 용어.** 공식 TXT의 위치와 개수를 정답(Ground Truth; GT)으로 사용한다. IoU는 예측 박스와 정답 박스의 겹침 비율이며, 운영점에서는 IoU 0.5를 기준으로 일대일 대응하여 정검출(TP)·미탐(FN)·오검출(FP)을 센다. 재현율은 TP/(TP+FN)이다. AP는 IoU 0.50~0.95의 COCO 평균 정밀도를 100점 척도로 표시하고, AP75는 IoU 0.75에서의 값이다. NMS는 겹치는 후보를 검출 점수 순으로 정리하는 후처리이다.

파일의 장비 코드 M1·M2·M3는 각각 **1호기·2호기·3호기 촬영 장비**를 뜻한다. 크기와 위치는 원본 영상 좌표에서 평가한다. 세 난수 초기값은 동일 데이터 분할에서의 학습 변동을 보여준다.

![학습·검증 자료는 작은 정답 박스와 특정 위치에 집중되어 있다](final_project/figures/figure_01_sampling.png)

**그림 1. 학습·검증 자료는 작은 정답 박스와 특정 위치에 집중되어 있다**. (a) 장비별 영상 수, (b) 정답 박스 짧은 변의 분포, (c) 영상 크기로 정규화한 검증 정답 중심이다. 크기 분포의 분모는 학습 797개·검증 144개이며, 교차 표시는 대표 모델의 미탐 2개이다. 단위는 원본 영상 픽셀로, 물리적 이물 지름과 구분한다.

### 2.2 모델 개발 과정 한눈에 보기

**실험 방향은 관측된 실패 원인에 따라 좁혀졌다.** 처음에는 특징 해상도를 높였고, 이후 후보 분석을 통해 학습 손실과 위치 품질 재점수화로 초점을 옮겼다. 후속 실험은 강한 대조군 대비 반복 일관성을 기준으로 채택 여부를 결정했다.

**표 1. 관찰에서 다음 실험으로 이어지는 판단 과정**. 각 행은 관찰·가설·통제 비교·채택 판단을 연결한다.

| 관찰 | 검증한 가설 | 무엇을 비교했는가 | 결과 및 판단 |
|---|---|---|---|
| 정답 박스가 작음 | 해상도 손실이 주요 병목일 수 있음 | 두 검출기 각각 기본형 대 고해상도 경로, 3개 난수 초기값 | AP와 낮은 FP 성과가 일관되지 않아 필수 구성에서 제외 |
| 정밀 후보의 존재와 선택 결과가 다름 | 감독 방식이 후보 품질을 개선할 수 있음 | D-FINE 대 동일 조건 MAL | 낮은 FP 검출 수는 개선했으나 AP는 감소; 목표별 효과 구분 |
| 점수와 위치 품질이 불일치 | 별도 품질 점수가 순위를 개선할 수 있음 | 같은 동결 검출기 대 UQ 추가 | AP +1.02, AP75 +1.63점; 낮은 FP TP는 동일 |
| UQ 후에도 지역 대표 선택이 정체 | 좋은 후보끼리의 순위 감독이 부족함 | 품질 손실 추가 학습 대 후보 쌍/목록 순위 감독 | MAL 계열 정밀 대표 수 평균 53.33개로 동일; 미채택 |
| 후보 특징만으로 경계 차이 구분이 어려움 | 주변 픽셀이 추가 단서를 제공할 수 있음 | 동일 파라미터 수의 대조군 대 국소 픽셀 입력 | 첫 seed에서 정밀 선택 개선 없음; 확대 보류 |
| 검은 점과 박스 여백 차이가 관찰됨 | 경계 불확실성 허용이 유리할 수 있음 | 경계 표현 대조군 대 1픽셀 완화, 각각 동일 UQ | AP75 개선 3회 중 1회; 최종 교체 기준 미충족 |

### 2.3 핵심 비교: 해상도, 학습 손실, 위치 품질

**최종 구성은 AP와 낮은 오검출 조건의 검출 수를 함께 고려해 선정했다.** YOLOv8s와 D-FINE-S의 기본 AP는 비슷했지만, D-FINE-S는 FP≤6 조건에서 더 많은 정답을 검출했다. 고해상도 경로 P2는 평균 AP를 높였으나 D-FINE에서는 같은 조건의 검출 수가 감소했다.

MAL은 D-FINE의 낮은 오검출 조건 검출 수를 140.33개에서 141.67개로 높였고, AP는 38.68에서 38.36으로 변했다. 그 위에 UQ를 추가하면 검출 수를 유지하면서 AP 39.38, AP75 19.05를 얻었다. **각 구성 요소의 기여는 서로 다른 지표에서 나타났다.**

**표 2. MAL+UQ는 검출 수를 유지하면서 AP와 AP75를 개선했다**. 검증 66장·정답 144개, 3회 반복의 평균 ± 표본 표준편차이다. FP≤6 TP는 반복별 오검출 6개 이하 운영점의 정검출 수이다.

| 모델 | AP | AP75 | FP≤6 TP/144 |
|---|---:|---:|---:|
| YOLOv8s | 38.75 ± 0.86 | 17.72 ± 1.69 | 137.33 ± 1.53 |
| YOLOv8s + 고해상도 경로 | 39.15 ± 0.80 | 19.49 ± 2.05 | 139.00 ± 1.00 |
| D-FINE-S | 38.68 ± 1.41 | 16.76 ± 0.71 | 140.33 ± 1.15 |
| D-FINE-S + 고해상도 경로 | 39.13 ± 0.63 | 18.51 ± 2.38 | 138.33 ± 2.89 |
| D-FINE-S + MAL | 38.36 ± 0.07 | 17.42 ± 2.03 | 141.67 ± 0.58 |
| D-FINE-S + MAL + UQ | 39.38 ± 0.62 | 19.05 ± 0.77 | 141.67 ± 0.58 |

![반복 실험은 평균 개선과 일관성을 함께 보여준다](final_project/figures/figure_05_ablation.png)

**그림 2. 반복 실험은 평균 개선과 일관성을 함께 보여준다**. 회색 점은 개별 반복, 파란 마름모와 오차 막대는 3회 평균과 표본 표준편차이다. AP·AP75·FP≤6 정검출 수를 각각 표시하며 패널별 축 범위가 다르다.

**UQ는 박스 좌표를 고정한 채 후보의 점수를 보정한다.** D-FINE의 경계 분포 정제 구조(Peng et al., 2025)에 DEIM의 매칭 인지 손실(Matchability-Aware Loss; MAL)을 적용했다(Huang et al., 2025). 이어 후보별 위치 품질 예측(Unary Quality; UQ)으로 점수와 IoU의 불일치를 다루었다.

UQ는 최종 query 특징, 경계 분포 통계, 기존 점수, 박스 기하를 입력하는 62,007개 파라미터의 경량 예측부이다. 검출기를 고정하고 후보와 정답 사이 최대 IoU를 학습하며, 최종 검출 점수는 기존 점수 p와 예측 위치 품질 q의 기하평균 √(p·q)로 계산한다. query는 후보를 표현하는 내부 특징 벡터이다.

UQ의 AP 증가와 함께 동일 이물 주변의 최고점수 후보 및 FP≤6 검출 수는 유지됐다. 따라서 **전역 점수 순위 개선과 같은 이물 안의 정밀 후보 선택을 구분**한다. 위치 품질 q는 IoU 학습값이며 실패 확률로 보정된 값과는 다르다.

![MAL 학습 뒤 UQ를 학습하여 점수 효과를 분리했다](final_project/figures/figure_07_method.png)

**그림 3. MAL 학습 뒤 UQ를 학습하여 점수 효과를 분리했다**. 첫 단계는 검출기 학습, 두 번째는 검출기를 고정한 UQ 학습이다. FDR은 D-FINE의 세분화 분포 정제 출력이다. UQ는 좌표를 유지하고 점수를 바꾸므로 NMS 처리 순서와 최종 선택에 영향을 줄 수 있다.

### 2.4 최종 모델과 대표 가중치 선정

**최종 구성은 D-FINE-S + MAL + UQ이며, 대표 가중치는 검증 AP 중앙값으로 선정했다.** 기존 3회 반복 중 난수 초기값 20260930을 선택해 단일 모델의 조건별 분석과 재현 패키지에 사용한다. 대표 선정 규칙은 2026-10-03에 정했으며, 시험셋 성능의 최댓값 대신 검증 AP를 기준으로 삼았다.

고정 설정 18회 실험의 시험셋(test) 평가는 이미 완료했다. MAL+UQ의 3회 평균은 **AP 37.46, AP50 93.29, AP75 15.88**, 검증 임계값을 그대로 적용한 정검출은 **196.33/206개**, 오검출은 **16.00개**였다. 대표 단일 모델의 검증 성능은 AP 39.28, AP75 19.66, TP 142개·FP 6개이다.

**평가 이력.** 시험 결과 이후 임계값을 재조정하지 않았다. 다만 팀의 이전 전처리 선택과 후속 연구에서 시험 결과를 열람한 이력이 있으므로, 시험 성능은 이 선택 이력을 함께 가진 고정 설정 평가로 제시한다.

### 2.5 후속 가설의 기각과 모델 탐색 종료

**추가 복잡도보다 반복 실험의 일관성을 우선해 모델 탐색을 종료했다.** 좋은 후보끼리 우열을 학습하는 후보 쌍 순위 감독(hard-pair)과 후보 목록 전체의 순서를 학습하는 listwise 감독을 비교했으나, MAL 계열의 정밀 대표 수는 평균 53.33개로 유지됐다. 정밀 대표 수는 근처 최고점수 후보의 IoU가 0.75 이상인 정답 수이다.

국소 픽셀 특징은 동일 파라미터 수 대조군과 비교한 첫 난수 초기값 실험에서 정밀 선택을 개선하지 못해 확대를 보류했다. 경계 모호성을 반영한 Soft1+UQ도 같은 실험 묶음의 edge+UQ 대비 AP75 개선이 3회 중 1회에 그쳤다. 이 결과를 근거로 기존 MAL+UQ를 유지했다.

![경계 완화의 평균 이득은 반복 일관성으로 이어지지 않았다](final_project/figures/figure_08_ambiguity_control.png)

**그림 4. 경계 완화의 평균 이득은 반복 일관성으로 이어지지 않았다**. Soft1+UQ와 edge+UQ를 같은 난수 초기값끼리 비교했다. edge는 좌·상·우·하 경계 좌표 손실 대조군, Soft1은 원본 1픽셀 수준 오차의 페널티를 완화한 방법이다. 평균 ΔAP75는 +0.59점이지만 두 반복에서 감소했고, 한 반복의 +2.93점에 의존했다. 반복 1·2·3의 초기값은 20260929·20260930·20261001이다.

경계 완화 실험 묶음에는 기존 MAL과의 재현 변동이 있어, 판단은 동일 묶음의 대조군 차이로 한정했다. 국소 픽셀 결과는 1회 선별 실험, 경계 완화 결과는 3회 반복 비교로 구분한다.

### 2.6 선행연구와 실제 적용 범위

**기존 연구의 아이디어를 데이터에서 확인한 병목에 맞춰 선택적으로 적용했다.** P2는 고해상도 가설 검증, MAL은 학습 손실 변경, UQ는 위치 품질에 따른 재점수화에 해당한다. 품질 추정의 문제의식은 GFLv2와 Rank-DETR에 연결된다(Li et al., 2021; Pu et al., 2023).

**표 3. 선행연구의 역할과 본 프로젝트의 적용 범위.** 참고한 개념과 실제 구현을 구분한다.

| 연구 | 연결되는 아이디어 | 본 프로젝트의 적용 |
|---|---|---|
| QueryDet (Yang et al., 2022) | 작은 물체를 위한 고해상도 특징 | 기존 검출기에 P2를 추가해 가설 검증 |
| D-FINE (Peng et al., 2025) | 경계 분포의 반복 정제와 자기증류 | 기본 검출기로 사용; 기존 위치 품질 추정 기능 포함 |
| DEIM (Huang et al., 2025) | 매칭 품질을 고려하는 MAL | MAL 손실 적용; Dense O2O 등은 적용 범위 밖 |
| GFLv2 (Li et al., 2021) | 경계 분포 기반 위치 품질 추정 | UQ 입력 설계와 연결 |
| Rank-DETR (Pu et al., 2023) | 점수와 위치 정확도의 불일치 | 후보 순위 진단의 근거; 원래 매칭·decoder 유지 |
| TIDE (Bolya et al., 2020) | 검출 오류의 원인 분해 | 저장 후보의 단계별 진단 체계에 참고 |
| Conformal Risk Control (Angelopoulos et al., 2024) | 별도 보정 자료를 이용한 위험 제어 | 현장 임계값 보정 제안에 참고 |

## 제3장 — 영향요인 및 오류분석

> **핵심 결론:** 대표 모델의 최종 미탐 2건은 이물 근처 후보가 존재하지만 공식 정답과의 경계 정렬이 부족한 사례였다. 장비·크기·위치·대비를 나누어 살펴보면 미탐의 위치는 드러나지만, 특정 조건 하나가 실패를 일으킨다는 단조적 경향은 뚜렷하지 않았다. 단계별 후보 분석으로 **발견·경계·선택 문제를 분리**했다.

### 3.1 후보부터 최종 출력까지의 실패 단계

**대표 모델의 두 미탐은 모두 ‘경계 정렬 부족’으로 분류됐다.** 최종 미탐 정답마다 NMS 이전 후보, NMS 이후 후보, 임계값 적용 결과를 차례로 확인했다. 오류를 분해하는 관점은 TIDE(Bolya et al., 2020)를 참고하되, 판정 규칙은 실제 저장 단계에 맞춰 구성했다.

**표 4. 실패 단계는 최초로 조건을 만족하는 지점으로 판정한다.** IoU 0.3은 근처 후보의 진단 기준, 0.5는 정검출 기준이다. 분석 대상은 검출 점수 0.001 이상 저장 후보이다.

| 단계 | 판정 규칙 | 확인할 대상 |
|---|---|---|
| 근처 후보 부재 | NMS 이전 최대 IoU < 0.3 | 저장된 후보 생성 결과 |
| 경계 정렬 부족 | NMS 이전 최대 IoU가 0.3 이상, 0.5 미만 | 공식 박스와의 위치·크기 차이 |
| NMS 탈락 | 이전에는 IoU ≥0.5 후보가 있으나 이후 없음 | 중복과 억제 순서 |
| 임계값 탈락 | NMS 이후 적합 후보가 있으나 운영점 이후 없음 | 후보 검출 점수 |
| 일대일 대응 충돌 | 운영점 이후 적합 후보가 있으나 정답과 매칭되지 않음 | 복수 정답과 예측의 대응 |

최대 IoU 후보와 최고점수 후보의 차이는 순위 불일치 지표로 따로 기록했다. 중복 검출과 영상 경보도 보조 축으로 관리하여, 같은 오류를 여러 미탐으로 중복 합산하지 않았다. ‘근처 후보 부재’의 범위는 저장 후보이며 내부 특징이나 저장 기준 아래 출력까지 포함하지 않는다.

### 3.2 장비와 정답 박스 크기별 성능

**미탐 2건은 모두 3호기에 있었고, 가장 작은 박스 구간은 17개 모두 검출됐다.** 크기만으로 실패를 설명하기보다 장비·촬영 조건·정답 박스 특성을 함께 살펴볼 필요가 있다.

**표 5. 장비와 크기를 함께 보면 평균 성능에 가려진 사례가 드러난다**. 대표 모델의 검증 66장·11개 촬영 그룹·정답 144개에 고정 임계값을 적용했다.

| 조건 | 영상/그룹 수 | GT | TP | FN | Recall |
|---|---:|---:|---:|---:|---:|
| 1호기 | 26/4 | 56 | 56 | 0 | 100% |
| 2호기 | 18/3 | 42 | 42 | 0 | 100% |
| 3호기 | 22/4 | 46 | 44 | 2 | 95.65% |
| TXT 짧은 변<8px | 12/4 | 17 | 17 | 0 | 100% |
| 8≤짧은 변<12px | 59/11 | 104 | 103 | 1 | 99.04% |
| 12≤짧은 변<16px | 11/2 | 22 | 22 | 0 | 100% |
| 짧은 변≥16px | 1/1 | 1 | 0 | 1 | 0% |

**해석 범위.** 크기는 공식 TXT 박스의 짧은 변이다. 한 영상에 여러 크기가 있어 크기별 영상 수는 중복될 수 있다. 16픽셀 이상 구간은 정답 1개이며, 장비와 촬영 조건도 함께 변하므로 이 표는 조건별 기술통계로 읽는다. 그룹 단위 재표집에서 3호기 재현율의 탐색 구간은 약 58.9~100%로 넓었다. 무오류 구간의 재표집 구간도 한 점으로 축소될 수 있어, 모집단 위험의 확신 구간 대신 표본 수와 오류 수를 함께 제시했다.

### 3.3 위치·대비·주변 밝기와 미탐

**미탐은 낮은 대비와 높은 대비 구간에 각각 1건씩 나타났다.** 현재 관측에서는 대비나 크기가 한 방향으로 변할수록 실패가 늘어나는 패턴보다, 개별 사례의 경계 정렬 차이가 두드러졌다.

조건 경계는 학습 정답 797개의 3분위값으로 정하고 검증셋에 적용했다. 대비 대리지표는 정답 내부와 주변의 평균 밝기 차이를 주변 변동으로 나눈 |μᵢ−μᵣ|/(σᵣ+1)이다. 위치·종횡비·주변 밝기 변동도 같은 방식으로 구간별 정검출 수를 비교했다.

**표 6. 위치와 영상 특성별 정검출 수를 분모와 함께 비교했다**. 각 셀은 TP/정답 수이다. 낮음·중간·높음은 학습셋에서 정한 두 경계로 구분하며, 경계값은 표시용으로 반올림했다.

**실패 사례에서도 이물 근처에는 경보 박스가 있었다.** 다만 대표 모델의 저장 후보 중 공식 IoU 0.5에 도달한 박스가 없었다. 성공 사례에서는 이미 검출됐더라도 최고점수 후보보다 더 정밀한 후보가 남아 있어, 박스의 존재와 점수 선택을 분리할 수 있었다.

**표 7. 두 미탐의 최대 IoU는 NMS 이전부터 0.5 미만이었다**. raw는 점수 0.001 이상 NMS 이전 후보, 경보 후보는 고정 임계값을 통과한 출력이다. 정답 번호는 분석 추적용이다.

**장 해석 범위.** 공식 TXT는 모든 비교의 기준으로 유지했다. 시각적 여백 차이는 경계 표기 민감성의 근거로 사용했고 정답 오류율로 환산하지 않았다. 검증의 양성 영상 66장 모두 경보가 있었지만 객체 수준에서는 2건의 미탐이 남았다. 이 구분을 다음 장의 검사 판단에 반영한다.

## 제4장 — 판정 임계값·재검사·현장 활용

> **핵심 결론:** 검출 성능과 검사 운영점은 별도로 관리해야 한다. 검증에서 정한 임계값을 시험셋에 적용하면 영상당 오검출 수준이 달라졌고, 단순 재검사 신호의 효과도 반복에 따라 변했다. 이에 **현장 자료로 임계값을 보정하고, 경보 위치와 검토 사유를 작업자에게 전달하는 흐름**을 제안한다.

**제안하는 사용 흐름**

X-ray 입력 → 입력 품질 확인 → 고정 모델 추론 → NMS·임계값 적용 → 경보 위치·검토 영역 표시 → 작업자 확인·격리·재촬영 → 결과 기록

탐지 결과는 이물 의심 경보로 전달한다. 무검출은 별도의 확인 상태로 남기며, 자동 통과 기준은 정상·불량 현장 자료를 확보한 뒤 정한다.

### 4.1 임계값을 어떻게 정해야 하는가?

**임계값을 낮추는 것만으로 남은 경계 정렬 미탐을 해결할 수는 없었다.** 대표 모델은 낮은 점수까지 포함해도 재현율이 142/144에서 포화됐다. 기존 비교 운영점은 검증 FP≤6에 해당하는 약 0.193이며, 정확한 값은 실행 설정에 보존했다.

![낮은 임계값에서도 대표 모델의 검출 수는 142개에서 포화된다](final_project/figures/figure_06_froc.png)

**그림 8. 낮은 임계값에서도 대표 모델의 검출 수는 142개에서 포화된다**. FROC는 객체 재현율과 영상당 오검출 박스 수의 관계이다. 왼쪽은 저장 후보 전체 범위, 오른쪽은 낮은 오검출 영역이다. 빨간 점은 FP 6/66장·TP 142/144개의 고정 운영점이다. 기존 예측으로 계산한 곡선이며 정상 제품 오경보 확률과 구분한다.

**검증 운영점의 오검출 수준은 시험셋에서 달라졌다.** MAL+UQ의 3회 평균 FP/영상은 검증 6/66≈0.091에서 시험 16/84≈0.190으로 증가했다. 시험셋에서 MAL의 FP는 평균 11.33개, MAL+UQ는 16.00개였다. UQ의 AP 개선과 고정 임계값의 오검출 변화는 따로 평가해야 한다.

![객체 검출, 양성 영상 경보, 오검출은 서로 다른 운영 특성을 보여준다](final_project/figures/figure_09_transfer.png)

**그림 9. 객체 검출, 양성 영상 경보, 오검출은 서로 다른 운영 특성을 보여준다**. MAL과 MAL+UQ의 기존 3회 평균이며, 검증은 66장·144개 정답, 시험은 84장·206개 정답이다. 검증에서 정한 반복별 임계값을 시험에도 고정 적용했다. 영상 경보는 박스가 하나라도 있는 상태로 정의한다.

현장 임계값은 다음 절차로 정한다.

1. 장비·제품 조건을 포함한 별도의 정상·불량 보정 자료를 확보한다.
2. 불량 제품의 무경보 통과 위험과 작업자의 검토 용량을 정한다.
3. 임계값별 재현율·영상당 오검출·제품 통과 오류를 계산한다.
4. 허용 위험을 충족하는 후보 중 검사 부담이 적은 운영점을 선택한다.
5. 새로운 촬영 그룹에서 고정 설정을 평가한다.

이 절차는 별도 자료를 이용한 위험 보정 연구와 연결된다(Angelopoulos et al., 2024). 본 프로젝트는 아래의 그룹 전이 실험으로 보정 필요성을 확인했고, 통계적 위험 보장 적용은 독립 현장 자료를 활용할 후속 단계로 둔다.

### 4.2 촬영 그룹이 바뀌어도 운영점이 유지되는가?

**평균 재현율 목표를 맞추는 것만으로 새 촬영 그룹의 목표 달성을 확보하기는 어려웠다.** 검증의 11개 그룹 중 하나를 제외하고 나머지 10개에서 임계값을 정한 뒤, 제외 그룹에 적용했다. 각 영상은 제외 그룹 평가에 한 번씩 포함됐다.

**표 8. 그룹 전이에서 오검출 예산 방식은 검출 수를 유지했고, 목표 재현율 방식은 목표 아래로 내려갔다**. 대표 단일 모델의 검증 66장·정답 144개 결과이다. fold는 한 그룹을 제외하는 평가 1회를 뜻한다.

| 보정 규칙 | 제외 그룹 TP / 144 | FN | FP | FP/영상 | 전체 재현율 | 보정 목표 불가능 fold |
|---|---:|---:|---:|---:|---:|---:|

| 전체 재현율 ≥98% | 140 | 4 | 2 | 0.030 | 97.22% | 0/11 |
| 각 보정 그룹 재현율 ≥95% | — | — | — | — | — | 10/11 |

오검출 예산 방식은 보정 자료에서 FP/영상≤0.1인 가장 낮은 저장 점수를, 목표 재현율 방식은 95% 또는 98%를 만족하는 가장 높은 점수를 사용했다. 오검출 예산 방식의 임계값은 약 0.186~0.193으로, TP 142개를 유지하면서 FP는 7개였다.

모든 보정 그룹에서 재현율 95%를 요구하면 11회 중 10회에서 조건을 충족할 임계값이 없었다. 유일하게 조건을 충족한 평가도 제외 그룹에서는 0/2개였다. 해당 그룹은 3호기 2020-07-27 촬영분이다. 조건을 충족하지 못한 평가는 운영 성과 집계에서 제외하고, 최저 점수 결과는 별도 진단으로 보존했다.

![그룹별 목표의 성립 여부까지 확인해야 임계값을 해석할 수 있다](final_project/figures/figure_11_group_transfer.png)

**그림 10. 그룹별 목표의 성립 여부까지 확인해야 임계값을 해석할 수 있다**. 왼쪽은 보정 조건을 충족한 평가의 제외 그룹 결과, 오른쪽은 보정 단계의 목표 미충족 횟수이다. 점 하나는 그룹 하나이며 같은 값은 겹친다. 그룹별 표본 수가 달라 각 비율은 해당 분모와 함께 읽는다.

이 비교는 모델 개발에 사용한 검증셋 안에서 수행한 탐색적 전이 분석이다. 시험셋을 이용해 새 임계값을 선택하지 않았다. Learn then Test와 Conformal Risk Control은 별도 보정 자료에서 판정 규칙을 정하는 관련 방법론이며, 본 분석은 단순 규칙의 전이 결과를 제시한다.

### 4.3 어떤 영상을 우선 재검사해야 하는가?

**낮은 후보 점수는 평균적으로 더 많은 미탐을 포함했지만, 효과가 모든 반복에서 유지되지는 않았다.** 낮은 점수·YOLO와의 박스 불일치·검출 개수 차이를 무작위 검토와 비교했다. 재검사 단위는 영상이고, 후보 박스는 검토 사유를 설명하는 데 사용한다.

**표 9. 재검사 신호별 미탐 포함 수를 무작위 검토와 비교했다**. 검증 66장에 대한 3회 평균이며, 전체 미탐은 반복별 3·2·2개이다. 값은 포함된 FN 개수의 평균이다.

| 검토 영상 수 (실제 비율) | 낮은 후보 점수 | 검출기 박스 불일치 | 검출 개수 차이 | 무작위 평균 |
|---|---:|---:|---:|---:|
| 4장 (6.1%) | 0.67 | 0.00 | 0.00 | 0.149 |
| 7장 (10.6%) | 0.67 | 0.33 | 0.00 | 0.257 |
| 14장 (21.2%) | 1.00 | 0.67 | 0.00 | 0.502 |

![작은 검토 예산에서는 신호의 효과가 반복마다 달랐다](final_project/figures/figure_10_review.png)

**그림 11. 작은 검토 예산에서는 신호의 효과가 반복마다 달랐다**. 패널별 전체 미탐은 3·2·2개, 실제 검토 예산은 4·7·14장이다. 점선과 회색 영역은 10,000회 무작위 선택의 평균과 2.5~97.5백분위 범위이다. 색 선은 신호로 고른 목록의 미탐 포함 수이며, 연결선은 이산 예산점의 읽기를 돕는다.

낮은 점수 신호는 두 번째 반복의 작은 예산에서 미탐을 포함하지 못했다. 개수 차이는 동점이 많아 선택 순서의 영향을 크게 받았다. 따라서 현재 적용안은 작은 검증셋에 새 가중합 점수를 맞추기보다, 검토 사유를 표시하고 작업자의 판단을 기록하는 방식이다.

검토 목록의 평가는 **미탐 포함률**과 **비검토 목록의 잔여 미탐**으로 나눈다. 실제 작업자의 확인 결과가 수집되면 회수율과 시간을 추가 평가한다. 기존 신호는 점수 0.25 이상 후보에서 계산했으며, 이는 최종 모델의 운영 임계값과 별개인 신호 계산 기준이다.

### 4.4 검토 영역은 어느 정도 넓혀 보여줄 것인가?

**박스에 작은 여백을 주면 주변 경계를 더 넓게 보여줄 수 있었다.** 2픽셀 여백에서 공식 정답 면적의 95% 이상을 포함한 사례는 45개에서 137개로 늘었고, 영상의 평균 표시 면적은 0.176%에서 0.337%로 증가했다.

기존 임계값을 통과한 예측 박스에 0·1·2·4·8픽셀 여백을 주고 영상 안으로 제한했다. 겹친 영역은 합집합 면적으로 계산했다. 영역 생성에는 예측만 사용하고, 공식 정답은 이후 포함도 평가에 사용했다. 공식 AP용 탐지 박스는 유지했다.

**표 10. 검토 영역의 포함도 증가와 화면 부담을 함께 비교했다**. 검증 66장·정답 144개이며 표시 영역 수는 평균 2.24개/영상으로 일정하다.

![여백은 정답 주변의 표시 범위를 넓히며 화면 면적도 늘린다](final_project/figures/figure_12_review_regions.png)

**그림 12. 여백은 정답 주변의 표시 범위를 넓히며 화면 면적도 늘린다**. 왼쪽은 정답 중심·면적 포함 수, 오른쪽은 영상별 표시 면적 비율의 평균과 95백분위이다. 평가 대상은 공식 TXT 영역이며, 백분위는 영상 간 분포를 나타낸다.

정답 중심은 여백 없이도 144개 모두 포함됐다. 이 분석이 측정한 것은 새로운 이물 발견보다 **주변 경계의 표시 범위**이다. 미탐 110은 기존 영역이 정답 면적의 약 35.0%를 포함했고, 4픽셀에서 약 80.7%, 8픽셀에서 전체를 포함했다. 미탐 136은 기존 영역이 약 95.1%를 포함하면서도 IoU 0.5에는 미달했다. 포함도와 위치 정밀도는 별도 지표로 유지한다.

Andeol et al. (2023)은 검출 불확실성과 출력 영역을 연결하는 관련 사례이다. 본 실험은 고정 픽셀 여백의 기하학적 비교이며, 적절한 여백의 운영 선택에는 별도 보정 자료와 작업자 평가를 사용한다.

### 4.5 다른 검출기를 함께 쓰면 보완되는가?

**대표 모델의 남은 미탐은 기존 YOLO 후보로도 보완되지 않았다.** 같은 난수 초기값의 고정 운영점에서 D-FINE+MAL+UQ는 142개, YOLO는 136개를 검출했고, 둘 중 하나가 검출한 정답의 합집합도 142개였다. 미탐 110·136에 대한 YOLO 저장 후보 최대 IoU는 각각 0.322·0.410이었다.

이 후보 상한 분석에 따라 추가 앙상블보다 현재 모델의 경보와 검토 설명을 정리하는 방향을 택했다. 합집합은 정답 기반 진단값이며 대표 반복의 결과로 한정한다.

### 4.6 현장 사용 흐름과 검사 보조 화면

**모델의 출력은 경보 위치와 확인할 영역으로 전달하도록 구현했다.** 최종 탐지 박스는 주황색, 2픽셀 검토 여백은 청록색으로 표시한다. 작업자는 의심 위치를 클릭하고 확인 내용을 남길 수 있다.

![실제 예측을 작업자가 확인할 수 있는 검사 화면으로 연결했다](final_project/figures/figure_13_review_interface.png)

**그림 13. 실제 예측을 작업자가 확인할 수 있는 검사 화면으로 연결했다**. 고정 모델의 검증 예측을 확대 영상에 표시하고 위치 클릭과 시간을 기록한다. 이 화면은 구현 예시이며 사람 비교 실험은 준비 단계이다.

화면 비교는 전처리 영상만, 박스 표시, 박스와 여백 표시의 세 조건으로 설계했다. 참가자별 66장을 조건당 22장씩 배정하고, A/B/C 배정군 간 같은 영상의 표시 조건을 순환시킨다. 같은 참가자에게 같은 파일은 한 번만 제시하고 정답과 개수는 숨긴다.

평가 항목은 공식 박스 안의 일대일 위치 클릭 성공률, 미대응 클릭 수, 활성 검토 시간이다. 사전 데이터 열람과 유사 촬영의 기억효과를 기록하고 참가자별 조건 차이를 먼저 비교한다. 현재는 도구·프로토콜과 소프트웨어 점검을 완료한 상태이다.

**표 11. 현장 판단에는 추론 시 얻을 수 있는 정보만 사용한다.** 사후 설명 지표와 운영 신호의 역할을 구분했다.

| 정보 | 역할 | 현재 활용 |
|---|---|---|
| 공식 박스 크기·위치·종횡비·정답 영역 대비 | 사후 오류 설명 | 조건별 분석 |
| 검출 점수·UQ 위치 품질·모델 불일치 | 검토 사유 후보 | 단순 신호 비교, 화면 표시 |
| 해상도·장비·촬영일·입력 형식 | 입력 점검과 이력 관리 | 운영 로그에 기록 |
| 물리적 밀도·재질·제품 경계·정상 여부 | 현장 검증의 추가 조건 | 별도 라벨과 자료 확보 대상 |

입력 형식 오류는 입력 단계에서 처리하고, 경보와 무검출 상태는 작업자의 격리·확인·재촬영 절차로 연결한다. 합성 데이터 담당자에게는 고정 가중치, 입력 변환, NMS, 임계값과 박스 경계 규칙을 전달한다. 합성 조건별 점수·IoU·검출·검토 사유는 실제 자료의 결과와 구분해 스트레스 테스트로 정리한다.

**장 해석 범위.** 현재 운영 분석은 양성 제품 영상과 저장 후보에 기반한다. 영상당 FP는 정상 제품의 오경보 확률과, 검토 목록의 미탐 포함은 실제 회수 효과와 각각 구분한다. 정상·불량 현장 자료와 작업자 결과를 확보하면 자동 통과 위험, 재검사 시간, 라인 부담을 평가할 수 있다. UQ 점수와 고정 여백 역시 이 현장 보정의 대상이다.

## 제5장 — 창의성 및 차별성

> **핵심 결론:** 본 연구의 차별성은 관측된 실패를 근거로 가설을 수정하고, 통제 비교를 통해 필요한 구성만 남긴 과정에 있다. MAL의 문제 맞춤 적용과 경량 UQ 설계에 더해, 객체 검출과 제품 경보를 분리하고 임계값 전이까지 분석했다. 개선이 일관되지 않은 실험도 최종 모델 선정과 탐색 종료의 근거로 활용했다.

### 5.1 데이터에서 출발한 설계와 검증

**새로운 구조의 복잡도보다 적용 이유와 실측 기여를 명확히 했다.** P2의 해상도 가설에서 시작해 후보의 경계·점수 문제로 초점을 옮기고, MAL과 UQ가 각각 어떤 지표를 바꾸는지 분리했다. UQ는 기존 품질 기반 검출 연구를 바탕으로 이 데이터의 점수–IoU 불일치에 맞춰 설계한 경량 재점수화 예측부이다.

**표 12. 프로젝트의 차별성은 설계·진단·운영을 연결한 근거에 있다.** 각 기여를 실제 비교 결과와 연결한다.

| 기여 | 실측 근거 | 적용 범위 |
|---|---|---|
| 실패에 따라 가설을 수정 | P2·MAL·UQ·순위·국소 특징·경계 완화 비교 | 현재 X-ray 데이터와 설정 |
| 경량 위치 품질 재점수화 | 같은 동결 검출기에서 AP +1.02, AP75 +1.63 | 기존 품질 추정 개념의 문제 맞춤 설계 |
| 객체 위치와 영상 경보 분리 | 객체 FN 2건과 양성 영상 66/66 경보 | 객체 검출과 영상 판단의 목적 구분 |
| 경계 표기 민감성 분석 | 실제 영상 및 경계 완화 대조 실험 | 공식 TXT 기준 유지 |
| 임계값과 검토 부담의 정량화 | 촬영 그룹 전이·무작위 검토 대조·영역 면적 | 현장 보정과 작업자 평가의 근거 |
| 재현 가능한 실행 패키지 | 새 가상환경에서 같은 예측·평가값 | 고정 가중치 추론·평가 |

UQ는 후보별 최대 IoU를 학습하므로 같은 이물의 여러 후보에 높은 품질을 줄 수 있다. 이 구조적 특성과 지역 대표 선택 결과를 함께 기록해, 전역 재점수화의 기여를 분명히 했다.

### 5.2 결과의 적용 범위와 확장 방향

**확보한 근거는 현재 데이터의 모델 선정과 운영 설계에 집중된다.** 일반화 범위에는 양성 제품 중심 자료, 반복 촬영과 제한된 조건, 검증셋 반복 활용, 적은 미탐 수, 과거 시험셋 활용 이력이 영향을 준다. 정답 기반 후보 상한과 경계 포함도는 진단용 지표로 유지한다.

확장은 두 축으로 나눈다. 합성 데이터에서는 크기·위치·대비 등의 조건을 제어해 고정 모델을 스트레스 테스트하고, 실제 현장에서는 정상·불량 제품과 작업자 결과로 임계값 및 재검사 부담을 평가한다. 두 자료의 박스 경계 규칙 차이도 함께 기록한다.

## 제6장 — 코드 구성 및 재현성

> **핵심 결론:** 고정 가중치의 추론·평가는 새 가상환경에서도 동일하게 재현됐다. MAL·UQ 학습 진입점과 실행 설정, 가중치, 분석 근거를 로컬 패키지로 정리했다. 재현 확인 범위는 같은 컴퓨터·GPU의 처리본 입력부터 평가까지이며, 전체 재학습과 다른 하드웨어 검증은 별도 범위로 명시한다.

### 6.1 고정 모델의 추론과 평가 재현

**새 가상환경에서 검증 66장의 모든 예측 좌표·점수·평가값이 일치했다.** 대표 모델의 AP 39.28, AP75 19.66, TP 142개·FP 6개를 재현했다. 추론은 정답 없이 수행하고, 평가 단계에서 파일명과 클래스 번호를 대응시킨다.

**표 13. 재현 패키지는 고정 추론과 학습 진입점을 구분해 점검했다.** 세부 환경·해시·검사 수치는 실행 자료에서 제공한다.

| 범위 | 점검 결과 | 제공 수준 |
|---|---|---|
| 처리본 → 학습 입력 | 영상·TXT·변환 정답 일치 | 자료 대응 확인 |
| MAL 학습 진입점 | 소량 배치 손실·역전파 유한성 확인 | 학습 진입 점검 |
| UQ 학습 진입점 | 예측부 갱신·검출기 고정 확인 | 학습 진입 점검 |
| 고정 모델 추론·평가 | 새 가상환경의 좌표·점수·평가값 일치 | 실행 재현 확인 |
| 전체 30+30 epoch 재학습 | 이번 패키지 감사에서는 미실행 | 설정과 진입점 제공 |

## 부록 — 본문 지표의 계산과 구현 세부

본문은 성과와 판단을 중심으로 구성하고, 재계산에 필요한 정의는 아래에 모았다.

- **AP와 운영점:** AP는 pycocotools 기본 COCO 박스 평가(maxDets=100)이다. 운영점 및 FROC는 점수 순 일대일 매칭을 사용한다. 원본 픽셀 좌표로 복원하고 저장 후보의 점수 하한은 0.001이다.
- **UQ 입력과 손실:** query 256차원, 네 경계별 상위 4개 확률 및 그 평균 20차원, 기존 점수 1차원, 중심·크기·로그 크기 6차원의 총 283차원이다. 후보와 정답의 최대 IoU를 목표로, 예측 품질과 목표 차이의 제곱으로 가중한 이진 교차 엔트로피를 사용한다.
- **대비 계산:** 주변은 정답 박스에서 max(3, round(max(폭, 높이)/2))픽셀 확장한 창에서 모든 정답 영역을 뺀 부분이다. 대비는 |μᵢ−μᵣ|/(σᵣ+1), 안정화 상수 1은 8비트 밝기 단위이다. 주변 표준편차는 밝기 변화·질감·잡음을 함께 반영한다.
- **조건 구간과 변동:** 학습 정답 797개의 3분위 경계를 사용한다. 조건 분석은 사후 분석이다. 그룹 재표집은 3,000회, 난수 초기값 20261003이며 무오류·전부오류 구간의 퇴화를 고려해 기술통계와 함께 보존한다.
- **검토 신호:** 점수 0.25 이상 후보를 대상으로 낮은 점수는 1−최저 점수, 박스 불일치는 1−(일대일 대응 IoU 합/더 많은 후보 수), 개수 차이는 후보 수 차이의 절댓값이다. 무후보 처리와 동점 순서는 코드에 고정했다. 검출기 간 점수 척도 차이도 해석에 고려한다.
- **검토 평가:** 미탐 포함률은 검토 목록 안 FN/전체 FN, 잔여 미탐은 전체 FN−목록 안 FN이다. 5·10·20% 예산은 66장 기준 올림한 4·7·14장이다. 실제 회수 효과는 작업자 확인 결과로 별도 측정한다.
- **영역 포함도:** 정답 박스와 검토 영역 합집합의 교집합 면적을 정답 면적으로 나눈 값이다. 연속 사각형 합집합으로 계산하고 일대일 검출 매칭을 요구하지 않는다. 표시 부담은 영상 면적 대비 합집합 면적이다.
- **사람 비교의 범위:** 정답 박스 내부 클릭의 성공은 물리적 이물 중심 판정과 구분한다. 넓은 정답 박스의 우연 포함, 참가자 경험, 사전 노출과 촬영 그룹 의존성을 함께 해석한다. 현재 실제 참가자 결과는 없다.
- **재현 확인 상세:** 학습·검증 영상과 TXT 832개를 대조했고, MAL은 8장 배치의 488개 기울기 텐서, UQ는 2배치 갱신을 점검했다. 새 환경의 NMS 이후 13,256개 예측이 일치했다. MAL 점검은 최적화 갱신 없이 수행했으며, 환경은 기존 패키지 폴더를 상속하지 않고 새로 설치했다. CUDA `grid_sample` 역전파의 비결정성을 재학습 해석에 반영한다.

원본 수치와 더 긴 감사 이력은 [보존된 기존 제출 초안](제출용_결과보고서_사용자담당.md) 및 [진행 보고서](프로젝트_진행과정_통합보고서.md)에 남아 있다. 실행용 소수점 정밀도·패키지 버전·설정 해시는 재현 패키지의 값을 사용한다.
