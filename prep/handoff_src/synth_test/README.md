# KAMP X-ray 합성 test 세트 v1 — 조건별 성능 평가 전용

**학습에 쓰지 마세요.** 팀 결정(2026-10-06)으로 합성 데이터는 평가(test) 전용입니다. 모델 학습과 임계값 결정은 메인 패키지(`kamp_xray_v2`)의 실제 train/val로 하고, 이 세트는 "실제 test에 없는 조건에서 모델이 어떻게 되는가"를 재는 데만 씁니다.

## 1. 왜 필요한가
실제 데이터의 결함은 모두 같은 표준 테스트피스입니다. 띠 끝 4곳에 있는 2~3px 금속 점뿐입니다. 그래서 실제 test 점수가 높아도 다음 조건에서의 성능은 알 수 없습니다.
- 결함이 늘 있던 자리(띠 끝)가 **아닌 곳**에 있을 때 → 지금 모델은 결함 위치를 외워서, 다른 자리 결함을 크게 놓칩니다(보고서 §4.5)
- 이물의 **크기·형상·재질**이 다를 때 (보고서 §4.6)

## 2. 구성
```
kamp_synth_test_v1/
├── images/{val,test}/*.png   8bit 흑백 단채널 (메인 패키지와 같은 형식, 마커 지운 배경)
├── labels/{val,test}/*.txt   YOLO 형식 (class 0 = defect). 실제 결함은 지워져 있어 합성 물체만 라벨에 있음
├── images.csv                영상별 세트·조건·원본 영상·장비
├── objects.csv               물체별 중심(obj_cx, obj_cy)·박스·평가 영역(ex1..ey2)·조건·대비
├── data.yaml                 ultralytics 용 (val, test만)
└── tools/eval_synth.py       조건별 평가
```
- **배경은 메인 패키지의 val 66장과 test 84장**입니다. 실제 결함을 지운 뒤 합성 물체를 넣었고, train 사진은 쓰지 않았습니다. 조건 비교는 `test`로 보고, 같은 조건의 `val`은 참고용입니다.
- 영상 이름은 `<원본 영상>__<세트>[__p<회차>]` 형식입니다.

| 세트 | 내용 | 영상 수 (val + test) |
|---|---|---:|
| `erased` | 실제 결함을 지운 영상. **결함 없는 제품의 대용**이며 라벨이 없음 | 150 |
| `pos_canon_k1.0`, `pos_canon_k0.5` | **원래 결함 자리(띠 끝)**에 다른 날 찍은 실제 결함을 옮겨 심음. k = 농도 배율(1 = 실제 농도) | 150씩 |
| `pos_random_k1.0`, `pos_random_k0.5` | 같은 결함을 **제품 안 무작위 자리** 3곳에 옮겨 심음 (4회) | 600씩 |
| `gvxr_size_x0.5` … `x5` | gVXR 물리 시뮬레이션 SUS304 구. 지름 = 실제 시편(약 0.25 mm) × 배수 | 300씩 |
| `gvxr_shape_*` | 부피는 시편과 같고 형상만 다름: 구 / 정육면체 / 불규칙 조각 / 판 / 선(길이 10배, 20배) | 300씩 |
| `gvxr_material_*` | 재질 SUS304 / Al / 유리 / 돌 / 뼈 / 플라스틱 × 지름 1·2·4·8배 | 300씩 |

- 옮겨 심기(`pos_*`)는 실제 결함의 광학 밀도 맵을 곱셈으로 넣은 것입니다. 원래 자리에서 실제 결함과 거의 구별되지 않음을 검증했습니다(보고서 §4.3).
- gVXR 이물은 모델 반응이 실제 결함과 가장 비슷하지만(상관 0.95 이상), 화소 수준에서는 구별됩니다(보고서 §4.6). 실제 예가 없는 조건이므로 **"통제 조건에서의 능력 한계"**로 해석하세요.
- 플라스틱과, 같은 크기의 비금속은 대비가 잡음 수준이라 **물리적으로 거의 보이지 않습니다**. 0%가 정상입니다.

## 3. 평가 방법
1. `images/test`(와 `images/val`) 전체에 모델을 돌려, 메인 패키지와 같은 CSV 형식으로 저장합니다. 좌표는 원본 픽셀 기준이고, **NMS 후 conf ≥ 0.001까지 모두** 넣으세요.
   ```csv
   image_id,x1,y1,x2,y2,conf
   001_20200622_203305(8)__pos_random_k1.0__p0,120.0,88.0,131.0,99.0,0.412
   ```
2. 평가합니다.
   ```bash
   python tools/eval_synth.py --pred preds_test.csv --split test                 # 기본 임계값 0.25
   python tools/eval_synth.py --pred preds_test.csv --split test --thr 0.25 0.5 --by machine
   ```
3. 출력의 열은 다음과 같습니다.
   - `detection_rate`: 세트별 검출률
   - `fp_per_image`: 짝 없는 검출 수의 영상당 평균
   - `any_det_rate`: `erased` 세트에서는 결함 없는 영상에 검출이 나온 비율입니다(낮을수록 좋음).

**찾음 규칙**은 신뢰도 ≥ 임계값인 검출의 중심이 물체 중심 8px 안이거나, 이물 영역을 4px 넓힌 사각형 안에 있는 경우입니다. 긴 선을 고려한 규칙입니다. 정답 박스 크기가 들쭉날쭉해서 IoU 대신 이 규칙을 씁니다. AP는 계산하지 않습니다.

## 4. 기준값 (보고서 결과, val + test 합계, 신뢰도 ≥ 0.25, seed 3개 평균)
이 패키지에 기존 모델을 돌려 `tools/eval_synth.py`로 계산한 값이 보고서 원본과 82개 조건 모두 일치함을 확인했습니다.

| 세트 | YOLOv8s ② COCO | D‑FINE‑S ② COCO |
|---|---:|---:|
| `pos_canon_k1.0` (원래 자리) | 100% | 100% |
| `pos_canon_k0.5` | 96% | 99% |
| `pos_random_k1.0` (다른 자리) | 41% | 84% |
| `pos_random_k0.5` | 14% | 48% |
| `gvxr_size_x1` (시편 크기) | 41% | 81% |
| `gvxr_size_x5` | 65% | 42% |
| `gvxr_shape_wire20` | 4% | 4% |
| `gvxr_material_stone_x4` | 5% | 33% |

원래 자리와 다른 자리의 차이가 클수록 모델이 결함 자체가 아니라 **위치**를 보고 있다는 뜻입니다. `erased`에서 원래 결함 자리에 반응하는 것도 같은 신호입니다. 정확한 val·test 수치는 `kamp-songsong` 저장소의 `REPORT.md` §4.5·§4.6을 보세요.
